## エグゼクティブサマリー

**【結論】フェーズ0→1の主戦場はTikTok一択ではなく「TikTok + Instagram Reels並走」が最優解**。TikTokは初動バズ力・レコメンド到達力で群を抜くが、占い×キャラの世界観醸成と外販導線（有料鑑定・グッズ・メンバーシップ）はInstagramが優位。YouTube（長尺）は1→10フェーズで登録者資産を積む「ストック型収益の柱」として不可欠。収益の天井を最大化するにはYouTubeライブ投げ銭（SuperChat）+ メンバーシップ + 外販の三重構造が最も大きく、短尺広告収益だけでは事業として成立しない。TikTokへのプラットフォーム依存リスク（米国等での禁止動向、誤BAN急増）には今から分散戦略が必要。

## 2. 占い×キャラクターコンテンツの相性分析

### 2-1. 各プラットフォームにおける占い系アカウントの成長事例

【事実】

**TikTok 占い系成功事例**
- 「3秒でわかる今日の恋愛運」「5秒診断・金運チェック」などの超短尺診断動画が完視聴率を稼ぎバズりやすい（AIうらない研究所 note記事、2024年）
- 総フォロワー2.6万人規模の占い・スピ系アカウントが2022年11月〜2023年2月で月売上43万円達成事例（rakkoma.com掲載案件）
- TikTok経由で占い依頼が直接来るケースが報告されている（AI占い×SNS集客記事、2024年）

**Instagram 占い系成功事例**
- ストーリーズで悩み募集 → DM個別相談 → 世界観投稿のサイクルでフォロワーを育てるモデルが有効（複数の占い運用者ブログより）
- タロット・星座・数秘術のリール動画は保存率が高く、インスタのアルゴリズムに適合しやすい
- 1アカウントで月20万円の収益を得る副業モデルが複数のnote記事で言及（2024〜2025年）

**YouTube 占い系成功事例**
- 「日本一当たる占いch」（登録者数推計数十万規模）のような専業チャンネルが複数存在（yutura.net YouTubeランキング掲載）

- 待受画像販売との組み合わせで月売上300万円超、動画講座との組み合わせで月1,000万円超えの事例あり

- テキスト占い・インプレッション収益の掛け合わせで月数万〜数十万円レンジの事例あり（収益化要件の閾値は高い）

【考察・示唆】: YouTubeの占い系チャンネルは「高単価×長視聴時間×外販導線」のトリプル構造で最も収益ポテンシャルが高い。TikTokは認知獲得の入口として最強だが、直接課金への転換導線設計が必要。

### 2-4. ショート動画における占い系のバイラルパターン

【事実・考察】

TikTokおよびInstagram Reelsにおける占い系のバイラルパターンは以下の3類型に収束する（複数のクリエイターブログ・事例記事より）:

1. **診断型**: 「あなたの誕生日で今月の金運がわかります」→ 完視聴率・コメント誘発が最強
2. **予言型**: 「〇〇座の人は今週これに注意」→ 拡散性高・保存率高
3. **キャラ投稿型**: AIキャラが「占い結果を告げる」演出 → TikTokのデュエット・ステッチで二次拡散

## 3. グロース戦略の違い

### 3-1. プラットフォーム別グロース戦略

**TikTok: レコメンド最強・初動が命・毎日投稿前提**
- フォロワー0から1動画でバズが起こりうる唯一のプラットフォーム
- 完視聴率（動画最後まで見られる率）が最重要。占い系は「結果を最後まで引っ張る」構成が有効
- 1日1〜2本投稿が基本（量産前提）
- アルゴリズム変動が最も激しく、2025年末〜2026年にかけて「有効視聴数（Qualified Views）」への移行で収益変動リスク増大

**YouTube: 登録者ストック・長尺SEO・リピート視聴**
- 検索流入（「〇〇座 今月 占い」等のキーワード）が長期的に蓄積する
- 一度作ったコンテンツが資産として機能（長尺動画は数年後も再生される）
- 収益化後はRPM 400〜600円/1,000再生と高単価
- SuperChat・メンバーシップとの組み合わせで収益の多角化が可能

**Instagram: 世界観・ビジュアル・リール+保存型**
- 占い×AIキャラの「見た目世界観」を最も強く訴求できるプラットフォーム
- 保存率が高いコンテンツ（星座別運勢画像・おみくじ風カルーセル）はアルゴリズム評価が高い
- ストーリーズでのリアルタイム交流 → DM → 外部鑑定サービスへの誘導導線が有効
- リール+保存の組み合わせはインスタの最優先シグナル

**ライブ配信プラットフォーム（YouTube Live / TikTok LIVE）: 滞在時間・投げ銭・コミュニティ**
- 占い師との対話・リアルタイム鑑定は投げ銭の動機付けとして最強コンテンツ形式
- YouTube SuperChat手数料：クリエイター取り分70%（App Store経由は実質50%）
- TikTok LIVE Gifts：クリエイター取り分約50%
- ライブはファンロイヤルティを最も高める形式であり、コア課金層の醸成に不可欠

## 4. クロスプラットフォーム戦略

### 4-1. マルチポストの効果と非効率

**効果**:
- 同一コンテンツをTikTok・Shorts・Reelsに横断投稿することで、1本制作の労力で3倍のリーチ機会
- 各プラットフォームのユーザーは重複が低く（TikTok専用層 vs YouTube専用層）、相互送客できる

**非効率・注意点**:
- TikTokに透かし（ウォーターマーク）が入った動画をYouTube ShortsやInstagram Reelsに転載するとアルゴリズムが降格させる（公式ガイドラインで明示）
- 各PFのアスペクト比・尺・テキスト位置が異なるため、完全な同一素材流用は品質を下げる
- 投稿文化・コメント文化が異なるため、同一キャプションの流用は離反を招く

**推奨**: 素材（映像本体）は共通化、テキスト・ハッシュタグ・サムネイルは各PF最適化を徹底する。

### 4-3. LINE/メルマガとの導線設計

【考察・示唆】

SNS → LINE公式アカウント → 外販（有料鑑定・グッズ・メンバーシップ）の三段階導線が最も収益効率が高い。

1. **認知**: TikTok/Instagram Reelsで無料占い動画 → フォロワー化
2. **育成**: YouTubeで詳細占いコンテンツ → チャンネル登録者化
3. **転換**: 「詳細な鑑定はLINE公式登録で無料プレゼント」でLINE登録誘導
4. **収益化**: LINE経由で有料占い・グッズ販売・メンバーシップ誘導

LINEはMAU 1億人超で日本最大のCRMチャネル。メッセージ開封率はメールの約10倍（業界推計）。

### 6-2. 占い・スピリチュアル系の規約変更動向

【考察・示唆】:

TikTok・YouTube・Instagramとも、占い系コンテンツ自体は現時点で禁止されていない。ただし以下の方向性に注意が必要:
- 「科学的根拠のない健康効果を謳う」コンテンツへの規制強化（特にYouTubeのヘルスポリシー）
- 「高額鑑定への誘導」がステルスマーケティングとして規制対象になる可能性
- 「AI占い師への過度な依存を助長するコンテンツ」への将来的な規制リスク

**対策**: コンテンツは「エンタメ占い」として明示し、科学的断言を避け、「楽しむための占い」という位置づけを一貫させる。

### 6-3. AI生成コンテンツへの規制強化動向

【事実・考察】:

- 2025年時点でTikTok・YouTube・Meta（Instagram）はすべてAIコンテンツへのラベル義務化を完了または施行中
- YouTubeは2025年7月にAI大量生産動画を収益化除外とする最初の大規模ポリシーを施行
- 今後2〜3年で「AIキャラが実在人物を偽る」「AIキャラが占い師として高額課金を誘導する」ケースへの規制が強化される見通し（業界動向からの推測）

**対策**: AIキャラであることを全面に出したIPブランディング戦略を選択（隠すのではなく、AI×エンタメとして訴求）。規約変更に備え、キャラクターIPとファンリストはSNS外（LINE・自社サービス）でも保有する。
