# /ma — M&A評価部ルーター

## このコマンドの役割

M&A評価部への指示をルーティングする。

**キーワード**: M&A、買収、バリュエーション、デューデリ、DD、PMI、シナジー、事業承継

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| 案件アナリスト | `agents/10-M&A評価部/案件アナリスト.md` | ソーシング・バリュエーション・DD |
| PMIプランナー | `agents/10-M&A評価部/PMIプランナー.md` | PMI計画・シナジー評価 |

## ルーティングロジック

```
「案件発掘・評価・DD」系 → 案件アナリスト
「PMI・統合計画・シナジー」系 → PMIプランナー
「M&A案件全体」系 → 案件アナリスト + PMIプランナー（並列）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「買収できそうな会社を調べて」 | 案件アナリスト |
| 「この会社の企業価値を算定して」 | 案件アナリスト |
| 「DDで確認すべきことをまとめて」 | 案件アナリスト |
| 「PMI計画を作って」 | PMIプランナー |
