# /ma — M&A評価部ルーター

## このコマンドの役割

M&A評価部への指示をルーティングする。

**キーワード**: M&A、買収、バリュエーション、デューデリ、DD、PMI、シナジー、事業承継

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| Koki | `agents/10-M&A評価部/koki.md` | 案件ソーシング |
| Nanami | `agents/10-M&A評価部/nanami.md` | バリュエーション |
| Akito | `agents/10-M&A評価部/akito.md` | デューデリジェンス |
| Kakeru | `agents/10-M&A評価部/kakeru.md` | PMI・シナジー評価 |

## ルーティングロジック

```
「案件発掘・情報収集」系 → Koki
「企業価値・価格算定」系 → Nanami
「リスク調査・DD」系 → Akito
「統合計画・シナジー」系 → Kakeru
「案件全体評価」系 → Koki + Nanami + Akito + Kakeru（段階的に起動）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「買収できそうな会社を調べて」 | Koki |
| 「この会社の企業価値を算定して」 | Nanami |
| 「DDで確認すべきことをまとめて」 | Akito |
| 「PMI計画を作って」 | Kakeru |
