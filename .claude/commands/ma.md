# /ma — M&A評価部ルーター

## このコマンドの役割

M&A評価部への指示をルーティングする。
ユーザーの指示内容を判断し、適切なエージェントをAgent toolの `subagent_type` で起動すること。

**キーワード**: M&A、買収、バリュエーション、企業価値、デューデリジェンス、DD、PMI、統合、シナジー、事業承継

## エージェント一覧

| エージェント名（subagent_type） | 専門 |
|-------------------------------|------|
| `案件アナリスト` | M&A案件ソーシング・企業価値算定・DD |
| `PMIプランナー` | 買収後統合計画・シナジー評価 |

## ルーティングロジック

```
「案件評価・バリュエーション・DD」系 → Agent tool (subagent_type: "案件アナリスト")
「PMI・統合・シナジー」系 → Agent tool (subagent_type: "PMIプランナー")
「M&A全体（評価から統合まで）」系 → 案件アナリスト → PMIプランナー（順次）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「この企業の価値を算定して」 | Agent tool → 案件アナリスト |
| 「DDのチェックリストを作って」 | Agent tool → 案件アナリスト |
| 「買収後の統合計画を作って」 | Agent tool → PMIプランナー |
| 「M&A案件を評価から統合計画まで」 | Agent tool → 案件アナリスト → PMIプランナー（順次） |
