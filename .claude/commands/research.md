# /research — リサーチ部ルーター

## このコマンドの役割

リサーチ部への指示をルーティングする。

**キーワード**: 市場調査、競合調査、トレンド、AI、技術、顧客の声、VOC、アンケート、助成金、補助金、政策

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| 市場調査員 | `agents/07-リサーチ部/市場調査員.md` | 市場・業界・競合・VOC調査 |
| トレンドウォッチャー | `agents/07-リサーチ部/トレンドウォッチャー.md` | AI・技術・助成金・政策動向 |

## ルーティングロジック

```
「市場・業界・競合・顧客」系 → 市場調査員
「AI・技術・助成金・政策」系 → トレンドウォッチャー
「総合調査」系 → 市場調査員 + トレンドウォッチャー（並列）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「市場規模を調べて」 | 市場調査員 |
| 「受講生のNPSを分析して」 | 市場調査員 |
| 「最新のAIトレンドをまとめて」 | トレンドウォッチャー |
| 「使える助成金を調べて」 | トレンドウォッチャー |
