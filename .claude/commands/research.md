# /research — リサーチ部ルーター

## このコマンドの役割

リサーチ部への指示をルーティングする。
ユーザーの指示内容を判断し、適切なエージェントをAgent toolの `subagent_type` で起動すること。

**キーワード**: 市場調査、競合調査、VOC、顧客の声、AI、技術トレンド、助成金、政策、補助金

## エージェント一覧

| エージェント名（subagent_type） | 専門 |
|-------------------------------|------|
| `市場調査員` | 市場規模・競合・VOC調査 |
| `トレンドウォッチャー` | AI・技術トレンド・助成金・政策動向 |

## ルーティングロジック

```
「市場・競合・VOC」系 → Agent tool (subagent_type: "市場調査員")
「AI・技術・助成金・政策」系 → Agent tool (subagent_type: "トレンドウォッチャー")
「市場全体の動向調査」系 → 市場調査員 + トレンドウォッチャー（並列）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「SES市場の規模を調べて」 | Agent tool → 市場調査員 |
| 「AI関連の助成金を探して」 | Agent tool → トレンドウォッチャー |
| 「市場動向と技術トレンドをまとめて」 | Agent tool → 市場調査員 + トレンドウォッチャー（並列） |
