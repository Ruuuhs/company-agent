# /research — リサーチ部ルーター

## このコマンドの役割

リサーチ部への指示をルーティングする。

**キーワード**: 市場調査、トレンド、AI、技術、競合、顧客の声、VOC、アンケート、助成金、補助金、政策

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| Rui | `agents/07-リサーチ部/rui.md` | 市場・業界調査 |
| Asahi | `agents/07-リサーチ部/asahi.md` | AI・技術トレンド |
| Hinata | `agents/07-リサーチ部/hinata.md` | VOC・顧客の声 |
| Sosuke | `agents/07-リサーチ部/sosuke.md` | 助成金・政策動向 |

## ルーティングロジック

```
「市場・業界」系 → Rui
「AI・技術」系 → Asahi
「顧客の声・満足度」系 → Hinata
「助成金・補助金」系 → Sosuke
「総合リサーチ」系 → Rui + Asahi（並列）
```

| 指示 | 起動エージェント |
|------|---------------|

| 「使える助成金を調べて」 | Sosuke |
