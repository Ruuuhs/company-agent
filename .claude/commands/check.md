このコマンドが実行されたとき、リポジトリのセットアップ状況を確認して報告してください。

---

## あなたの役割

あなたは「セットアップチェッカー」です。
リポジトリの各ファイルを確認し、「設定できている部分」と「まだ未設定の部分」を分かりやすく報告します。

---

## 確認手順

### ステップ1: 各ファイルを確認する

以下のファイルをすべて読んでください。

**会社情報（guidelines/）:**
- `guidelines/company-overview.md` — 会社名・事業内容・ターゲット顧客が入力されているか
- `guidelines/ceo-style-guide.md` — 代表の口調・使用表現が設定されているか
- `guidelines/brand-guidelines.md` — ブランドカラー・キーワードが設定されているか

**エージェント（agents/）:**
- 全エージェントファイルが存在するか
- 各ファイルが 100 行以上あるか（短すぎる場合は未完成の可能性あり）

**コマンド（.claude/commands/）:**
- 10 個のコマンドファイルが揃っているか

### ステップ2: 結果を報告する

以下の形式で報告してください。

```
## セットアップ状況レポート

### 会社情報
| 項目 | 状態 | 対応方法 |
|-----|------|---------|
| 会社名 | ✅ 設定済み / ❌ 未設定 | （未設定の場合）/setup で設定できます |
| 事業内容 | ... | ... |
| 代表スタイル | ... | ... |
| ブランドカラー | ... | ... |

### AI社員（エージェント）
| 部門 | 人数 | 状態 |
|-----|------|------|
| 経営企画部 | 3人 | ✅ |
| ... | ... | ... |

### 総合評価
（設定状況を一言でまとめる）

### 次にやること
（未設定の項目がある場合、優先順位をつけて案内する）
```

### ステップ3: アドバイス

未設定の項目がある場合は、対応するコマンドを案内してください。

- 会社情報が未設定 → `/setup` を実行するよう案内
- エージェントを追加したい → `/add-agent` を実行するよう案内
- 特定のファイルを直接編集したい → ファイルパスを教える
