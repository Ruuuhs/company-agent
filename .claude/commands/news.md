# /news — ニュース収集ルーター

## このコマンドの役割

AI・技術・業界・競合・政策など、あらゆる「ニュース収集」依頼をリサーチ部のエージェントに振り分けるルーターです。

このコマンドが呼ばれたとき、司令塔は **必ず Agent tool で担当エージェントを起動** してください。自分でニュースを収集・要約せず、ルーティングに徹します。

**キーワード**: ニュース、速報、最新、動向、アップデート、プレスリリース、発表、リリース、報道、記事、トピック、業界ニュース、競合ニュース、AIニュース、政策ニュース

## ルーティングロジック

```
「AI・技術・生成AI・SaaS・セキュリティ」系ニュース      → トレンドウォッチャー
「助成金・補助金・法改正・規制・政策」系ニュース        → トレンドウォッチャー
「市場・業界・競合・他社プレスリリース」系ニュース      → 市場調査員
「顧客動向・VOC・業界レポート」系ニュース              → 市場調査員
「総合ニュースまとめ・週次/月次レポート」            → トレンドウォッチャー + 市場調査員（並列起動）
```

複数領域にまたがる場合は、**関連エージェントを Agent tool で並列起動** し、司令塔が結果を1本のレポートに統合して報告します。

## アウトプットの必須項目

各エージェントには、以下の項目を **必ず含めてレポートを作成する** よう指示してください。

| 必須項目 | 内容 |
|---------|------|
| **ニュースサマリー** | 1件につき2〜4行で要点を平易にまとめる |
| **出典URL** | 一次情報（公式プレスリリース・省庁発表等）を優先 |
| **発行日（YYYY-MM-DD）** | 各ニュースの発行日・更新日を明記。古い情報を現在形で書かない |
| **自社への示唆** | 自社事業にとってのチャンス / 脅威 / 様子見、および推奨アクション |

---

## 鮮度・品質ルール（強調事項）

- **鮮度管理を最優先**：各ニュースの発行日を必ず明記し、古い情報を最新のように扱わない。レポート冒頭に「情報取得日」を入れる
- **信頼できる情報源を優先**：公式発表 > 大手業界メディア > 個人ブログ・匿名投稿の順で扱う。一次情報にアクセスできない場合はその旨を記す
- **重複排除**：同一トピックが複数ソースで報じられている場合は1件に統合し、最も信頼度の高い出典を主として他を補足扱いにする
- **自社との関連度でフィルタリング**：自社事業に無関係なニュースを大量に列挙しない。「自社への示唆」が書けないニュースは原則除外
- 詳細な収集・整理手順は `guidelines/research-protocol.md` を参照すること
