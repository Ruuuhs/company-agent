# /data — データ分析部ルーター

## このコマンドの役割

データ分析部への指示をルーティングする。

**キーワード**: KPI、データ、分析、グラフ、可視化、ABテスト、コホート、統計、レポート

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| Shun | `agents/08-データ分析部/shun.md` | KPIモニタリング |
| Sakura | `agents/08-データ分析部/sakura.md` | 深堀り・コホート分析 |
| Io | `agents/08-データ分析部/io.md` | ABテスト設計・検定 |
| Tsumugi | `agents/08-データ分析部/tsumugi.md` | グラフ・可視化 |

## ルーティングロジック

```
「KPI・定点観測」系 → Shun
「深堀り・原因分析」系 → Sakura（+ Shun のデータを活用）
「ABテスト」系 → Io
「可視化・グラフ」系 → Tsumugi
「総合分析レポート」系 → Shun + Sakura + Tsumugi（並列）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「今週のKPIをまとめて」 | Shun |
| 「継続率が下がった原因を分析して」 | Sakura |
| 「このABテストの結果を判定して」 | Io |
| 「データをグラフにして」 | Tsumugi |
