# /data — データ分析部ルーター

## このコマンドの役割

データ分析部への指示をルーティングする。

**キーワード**: KPI、データ、分析、グラフ、可視化、ABテスト、コホート、統計、レポート

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| KPIアナリスト | `agents/08-データ分析部/KPIアナリスト.md` | KPIモニタリング・深堀り・ABテスト・可視化 |

## ルーティングロジック

```
KPIアナリストがデータ分析全般を一元的に担当する。
必要に応じてコホート・ABテスト・可視化も同一エージェントが対応する。
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「今週のKPIをまとめて」 | KPIアナリスト |
| 「継続率が下がった原因を分析して」 | KPIアナリスト |
| 「このABテストの結果を判定して」 | KPIアナリスト |
| 「データをグラフにして」 | KPIアナリスト |
