# /data — データ分析部ルーター

## このコマンドの役割

データ分析部への指示をルーティングする。
ユーザーの指示内容を判断し、適切なエージェントをAgent toolの `subagent_type` で起動すること。

**キーワード**: KPI、データ分析、ABテスト、数値、グラフ、可視化、ダッシュボード、レポート

## エージェント一覧

| エージェント名（subagent_type） | 専門 |
|-------------------------------|------|
| `KPIアナリスト` | KPIモニタリング・深堀り分析・ABテスト設計・データ可視化 |

## ルーティングロジック

```
すべてのデータ分析系タスク → Agent tool (subagent_type: "KPIアナリスト")
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「今月のKPIをまとめて」 | Agent tool → KPIアナリスト |
| 「ABテストの設計をして」 | Agent tool → KPIアナリスト |
| 「売上データを分析して」 | Agent tool → KPIアナリスト |
