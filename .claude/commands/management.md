# /management — 経営管理部ルーター

## このコマンドの役割

経営管理部への指示をルーティングする。
ユーザーの指示内容を判断し、適切なエージェントをAgent toolの `subagent_type` で起動すること。

**キーワード**: 経費、予算、会計、財務、予実、契約、法務、利用規約、リスク

## エージェント一覧

| エージェント名（subagent_type） | 専門 |
|-------------------------------|------|
| `財務コントローラー` | 経費チェック・予算管理・予実対比 |
| `法務チェッカー` | 契約書・利用規約・法的リスク |

## ルーティングロジック

```
「経費・予算・会計」系 → Agent tool (subagent_type: "財務コントローラー")
「契約・法務・利用規約」系 → Agent tool (subagent_type: "法務チェッカー")
「予算を伴う契約」系 → 財務コントローラー + 法務チェッカー（並列）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「今月の経費を確認して」 | Agent tool → 財務コントローラー |
| 「この契約書をチェックして」 | Agent tool → 法務チェッカー |
| 「予算を含む新規取引の契約を確認」 | Agent tool → 財務コントローラー + 法務チェッカー（並列） |
