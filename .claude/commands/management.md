# /management — 経営管理部ルーター

## このコマンドの役割

経営管理部への指示をルーティングする。

**キーワード**: 経費、予算、会計、勘定科目、予実、法務、契約、規約、リスク

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| Kento | `agents/06-経営管理部/kento.md` | 経費チェック・勘定科目 |
| Mio | `agents/06-経営管理部/mio.md` | 予算管理・予実対比 |
| Ritsu | `agents/06-経営管理部/ritsu.md` | 契約・法務リスク |

## ルーティングロジック

```
「経費・会計」系 → Kento
「予算・予実」系 → Mio（+ Kento と連携）
「契約・法務」系 → Ritsu
「財務全般」系 → Kento + Mio（並列）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「今月の経費を確認して」 | Kento |
| 「予実対比レポートを作って」 | Mio |
| 「この契約書のリスクを確認して」 | Ritsu |
