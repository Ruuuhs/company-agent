# /management — 経営管理部ルーター

## このコマンドの役割

経営管理部への指示をルーティングする。

**キーワード**: 経費、予算、会計、勘定科目、予実、法務、契約、規約、リスク

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| 財務コントローラー | `agents/06-経営管理部/財務コントローラー.md` | 経費・予算・予実管理 |
| 法務チェッカー | `agents/06-経営管理部/法務チェッカー.md` | 契約・法務リスク |

## ルーティングロジック

```
「経費・予算・会計」系 → 財務コントローラー
「契約・法務」系 → 法務チェッカー
「契約に伴う経費確認」系 → 財務コントローラー + 法務チェッカー（並列）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「今月の経費を確認して」 | 財務コントローラー |
| 「予実対比レポートを作って」 | 財務コントローラー |
| 「この契約書のリスクを確認して」 | 法務チェッカー |
