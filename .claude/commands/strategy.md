# /strategy — 経営企画部ルーター

## このコマンドの役割

経営企画部への指示をルーティングする。

**キーワード**: 戦略、経営計画、中長期、ロードマップ、OKR、KGI、方針、事業計画、競合分析、差別化、会議、議事録、アジェンダ

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| 戦略立案者 | `agents/01-経営企画部/戦略立案者.md` | 中長期戦略・事業計画 |
| 競合アナリスト | `agents/01-経営企画部/競合アナリスト.md` | 競合分析・差別化 |
| 議事録担当 | `agents/01-経営企画部/議事録担当.md` | 会議・議事録・アクション管理 |

## ルーティングロジック

```
「戦略・計画」系 → 戦略立案者
「競合・市場・差別化」系 → 競合アナリスト
「会議準備・議事録」系 → 議事録担当
「複合タスク（戦略全体）」系 → 戦略立案者 + 競合アナリスト（並列）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「来期の事業計画を作って」 | 戦略立案者 |
| 「競合の動向をまとめて」 | 競合アナリスト |
| 「会議のアジェンダを作って」 | 議事録担当 |
| 「来期の全体戦略と競合分析を同時に」 | 戦略立案者 + 競合アナリスト（並列）|

## 連携部門

- データ分析部（KPIアナリスト）: 実績データの収集
- リサーチ部（市場調査員）: 市場・競合調査データ
- 経営管理部（財務コントローラー）: 財務データ
