# /strategy — 経営企画部ルーター

## このコマンドの役割

経営企画部への指示をルーティングする。
ユーザーの指示内容を判断し、適切なエージェントをAgent toolの `subagent_type` で起動すること。

**キーワード**: 戦略、経営計画、中長期、ロードマップ、OKR、KGI、方針、事業計画、競合分析、差別化、会議、議事録、アジェンダ

## エージェント一覧

| エージェント名（subagent_type） | 専門 |
|-------------------------------|------|
| `戦略立案者` | 中長期戦略・事業計画 |
| `競合アナリスト` | 競合分析・差別化 |
| `議事録担当` | 会議・議事録・アクション管理 |

## ルーティングロジック

ユーザーの指示を判断し、Agent toolで以下のように起動すること。

```
「戦略・計画」系 → Agent tool (subagent_type: "戦略立案者")
「競合・市場・差別化」系 → Agent tool (subagent_type: "競合アナリスト")
「会議準備・議事録」系 → Agent tool (subagent_type: "議事録担当")
「複合タスク（戦略全体）」系 → 戦略立案者 + 競合アナリスト を並列起動
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「来期の事業計画を作って」 | Agent tool → 戦略立案者 |
| 「競合の動向をまとめて」 | Agent tool → 競合アナリスト |
| 「会議のアジェンダを作って」 | Agent tool → 議事録担当 |
| 「来期の全体戦略と競合分析を同時に」 | Agent tool → 戦略立案者 + 競合アナリスト（並列） |

## 連携部門

- データ分析部（KPIアナリスト）: 実績データの収集
- リサーチ部（市場調査員）: 市場・競合調査データ
- 経営管理部（財務コントローラー）: 財務データ
