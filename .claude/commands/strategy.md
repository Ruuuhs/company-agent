# /strategy — 経営企画部ルーター

## このコマンドの役割

経営企画部への指示をルーティングする。以下のキーワードが含まれる場合に起動する。

**キーワード**: 戦略、経営計画、中長期、ロードマップ、OKR、KGI、方針、事業計画、競合分析、差別化、会議、議事録、アジェンダ

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| Haruto | `agents/01-経営企画部/haruto.md` | 中長期戦略・事業計画 |
| Mei | `agents/01-経営企画部/mei.md` | ロードマップ・実行計画 |
| Kaito | `agents/01-経営企画部/kaito.md` | 競合分析・差別化 |
| Riko | `agents/01-経営企画部/riko.md` | 会議・議事録 |

## ルーティングロジック

```
「戦略・計画」系 → Haruto + Mei（必要に応じて並列）
「競合・市場」系 → Kaito（+ Rui@リサーチ部 と連携）
「会議準備」系 → Riko
「複合タスク」系 → Haruto（統括）+ 必要なエージェントを並列起動
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「来期の事業計画を作って」 | Haruto + Mei（並列） |
| 「競合の動向をまとめて」 | Kaito |
| 「会議のアジェンダを作って」 | Riko |
| 「来期の全体戦略と実行計画を作って」 | Haruto + Mei + Kaito（並列）|

## 連携部門

- データ分析部（Shun）: 実績データの収集
- リサーチ部（Rui）: 市場調査データ
- 経営管理部（Kento/Mio）: 財務データ
