# /business-dev — 事業開発部ルーター

## このコマンドの役割

事業開発部への指示をルーティングする。

**キーワード**: 新規事業、新サービス、新コース、企画、収益モデル、価格、満足度、継続率、完了率、パートナー、BPO、業務委託

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| Sota | `agents/02-事業開発部/sota.md` | 新サービス企画 |
| Koharu | `agents/02-事業開発部/koharu.md` | 満足度・継続率改善 |
| Ren | `agents/02-事業開発部/ren.md` | パートナー連携・BPO |
| Risa | `agents/02-事業開発部/risa.md` | 価格戦略・収益モデル |

## ルーティングロジック

```
「新規事業・企画」系 → Sota
「顧客満足・継続」系 → Koharu（+ Hinata@リサーチ部 と連携）
「外部パートナー」系 → Ren（+ Ritsu@経営管理部 と連携）
「価格・収益」系 → Risa（+ Shun@データ分析部 と連携）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「新しいコースを企画して」 | Sota |
| 「継続率が下がっているので改善策を」 | Koharu |
| 「外注できる業務を整理して」 | Ren |
| 「価格を見直したい」 | Risa |
