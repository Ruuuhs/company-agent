# /business-dev — 事業開発部ルーター

## このコマンドの役割

事業開発部への指示をルーティングする。

**キーワード**: 新規事業、新サービス、新コース、企画、収益モデル、価格、価格改定、満足度、継続率、完了率、パートナー、BPO、業務委託

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| 事業企画者 | `agents/02-事業開発部/事業企画者.md` | 新サービス・コース企画 |
| 収益設計者 | `agents/02-事業開発部/収益設計者.md` | 価格戦略・収益モデル・外部連携 |

## ルーティングロジック

```
「新規事業・企画」系 → 事業企画者
「価格・収益・パートナー」系 → 収益設計者
「新規事業の収益化まで含む」系 → 事業企画者 + 収益設計者（並列）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「新しいコースを企画して」 | 事業企画者 |
| 「価格を見直したい」 | 収益設計者 |
| 「外注できる業務を整理して」 | 収益設計者 |
| 「新サービスの企画から価格設定まで」 | 事業企画者 + 収益設計者（並列） |
