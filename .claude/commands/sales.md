# /sales — 営業部ルーター

## このコマンドの役割

営業部への指示をルーティングする。

**キーワード**: 営業、受託、提案書、見積、見積書、商談、議事録、契約書、NDA

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| 営業サポート | `agents/09-営業部/営業サポート.md` | 商談・提案書・見積書 |
| 契約ライター | `agents/09-営業部/契約ライター.md` | 契約書・NDA |

## ルーティングロジック

```
「商談・提案書・見積」系 → 営業サポート
「契約書・NDA」系 → 契約ライター（法務チェッカーと連携）
「案件まるごと」系 → 営業サポート → 契約ライター（順次）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「商談の議事録をまとめて」 | 営業サポート |
| 「提案書を作って」 | 営業サポート |
| 「見積書を作って」 | 営業サポート |
| 「NDAを作って」 | 契約ライター |
