# /sales — 営業部ルーター

## このコマンドの役割

営業部への指示をルーティングする。

**キーワード**: 営業、受託、提案書、見積、見積書、商談、議事録、契約書、NDA

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| Ryota | `agents/09-営業部/ryota.md` | 受託営業・議事録分析 |
| Honoka | `agents/09-営業部/honoka.md` | 提案書作成 |
| Daiki | `agents/09-営業部/daiki.md` | 見積書・工数算定 |
| Kai | `agents/09-営業部/kai.md` | 契約書・NDA |

## ルーティングロジック

```
「商談・営業戦略」系 → Ryota
「提案書」系 → Honoka（Ryotaから商談情報を受け取り）
「見積・工数」系 → Daiki
「契約・NDA」系 → Kai（+ Ritsu@経営管理部 と連携）
「案件まるごと」系 → Ryota + Honoka + Daiki（並列→Kaiへ順次）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「商談の議事録をまとめて」 | Ryota |
| 「提案書を作って」 | Honoka |
| 「見積書を作って」 | Daiki |
| 「NDAを作って」 | Kai |
