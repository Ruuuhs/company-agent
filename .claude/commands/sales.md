# /sales — 営業部ルーター

## このコマンドの役割

営業部への指示をルーティングする。
ユーザーの指示内容を判断し、適切なエージェントをAgent toolの `subagent_type` で起動すること。

**キーワード**: 受託、提案書、見積、商談、議事録、契約書、NDA、業務委託

## エージェント一覧

| エージェント名（subagent_type） | 専門 |
|-------------------------------|------|
| `営業サポート` | 商談議事録・提案書・見積書 |
| `契約ライター` | 契約書・NDA作成 |

## ルーティングロジック

```
「提案書・見積・商談」系 → Agent tool (subagent_type: "営業サポート")
「契約書・NDA」系 → Agent tool (subagent_type: "契約ライター")
「商談から契約まで一貫して」系 → 営業サポート + 契約ライター（順次）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「提案書を作って」 | Agent tool → 営業サポート |
| 「見積書を作成して」 | Agent tool → 営業サポート |
| 「NDAのドラフトを作って」 | Agent tool → 契約ライター |
| 「商談から契約書まで一式準備して」 | Agent tool → 営業サポート → 契約ライター（順次） |
