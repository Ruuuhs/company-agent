# /hr — 人事部ルーター

## このコマンドの役割

人事部への指示をルーティングする。

**キーワード**: 採用、求人、面接、評価、組織、オンボーディング、人材、研修

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| 採用マネージャー | `agents/05-人事部/採用マネージャー.md` | 採用戦略・求人票・面接設計 |
| 組織デザイナー | `agents/05-人事部/組織デザイナー.md` | 組織設計・オンボーディング |

## ルーティングロジック

```
「採用・求人・面接」系 → 採用マネージャー
「組織・オンボーディング」系 → 組織デザイナー
「採用から入社まで全部」→ 採用マネージャー + 組織デザイナー（並列→連携）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「エンジニアの求人票を作って」 | 採用マネージャー |
| 「面接の評価シートを作って」 | 採用マネージャー |
| 「新人のオンボーディング計画を作って」 | 組織デザイナー |
