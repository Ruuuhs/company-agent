# /hr — 人事部ルーター

## このコマンドの役割

人事部への指示をルーティングする。
ユーザーの指示内容を判断し、適切なエージェントをAgent toolの `subagent_type` で起動すること。

**キーワード**: 採用、面接、求人、人材、組織、オンボーディング、研修、体制

## エージェント一覧

| エージェント名（subagent_type） | 専門 |
|-------------------------------|------|
| `採用マネージャー` | 採用戦略・求人票・面接設計 |
| `組織デザイナー` | 組織設計・オンボーディング |

## ルーティングロジック

```
「採用・面接・求人」系 → Agent tool (subagent_type: "採用マネージャー")
「組織・オンボーディング・研修」系 → Agent tool (subagent_type: "組織デザイナー")
「採用から入社後まで一貫して」系 → 採用マネージャー + 組織デザイナー（並列）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「エンジニアを採用したい」 | Agent tool → 採用マネージャー |
| 「オンボーディングを整備して」 | Agent tool → 組織デザイナー |
| 「採用から入社後の立ち上げまで計画して」 | Agent tool → 採用マネージャー + 組織デザイナー（並列） |
