# /hr — 人事部ルーター

## このコマンドの役割

人事部への指示をルーティングする。

**キーワード**: 採用、求人、面接、評価、組織、オンボーディング、人材、研修

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| Minato | `agents/05-人事部/minato.md` | 採用戦略・求人票 |
| Sana | `agents/05-人事部/sana.md` | 面接設計・評価シート |
| Yuto | `agents/05-人事部/yuto.md` | 組織設計・オンボーディング |

## ルーティングロジック

```
「採用・求人」系 → Minato
「面接・評価」系 → Sana（Minatoと連携）
「組織・オンボーディング」系 → Yuto
「採用から入社まで全部」→ Minato + Sana + Yuto（並列→順次）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「エンジニアの求人票を作って」 | Minato |
| 「面接の評価シートを作って」 | Sana |
| 「新人のオンボーディング計画を作って」 | Yuto |
