# /marketing — マーケティング部ルーター

## このコマンドの役割

マーケティング部への指示をルーティングする。

**キーワード**: X、Twitter、SNS、投稿、プレスリリース、広報、LP、コピー、広告、メルマガ、LINE、CRM

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| SNSライター | `agents/04-マーケティング部/SNSライター.md` | X運用・投稿文案 |
| PRライター | `agents/04-マーケティング部/PRライター.md` | プレスリリース・広報 |
| コピーライター | `agents/04-マーケティング部/コピーライター.md` | LP・広告・コピー全般 |
| CRMマネージャー | `agents/04-マーケティング部/CRMマネージャー.md` | メルマガ・LINE・CRM |

## ルーティングロジック

```
「X・SNS投稿」系 → SNSライター
「プレスリリース・広報」系 → PRライター
「LP・コピー・広告」系 → コピーライター
「メルマガ・LINE・CRM」系 → CRMマネージャー
「キャンペーン全体」系 → SNSライター + コピーライター（並列）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「Xの投稿案を5つ作って」 | SNSライター |
| 「プレスリリースを作って」 | PRライター |
| 「LPのコピーを改善して」 | コピーライター |
| 「今月のメルマガを書いて」 | CRMマネージャー |
