# /marketing — マーケティング部ルーター

## このコマンドの役割

マーケティング部への指示をルーティングする。
ユーザーの指示内容を判断し、適切なエージェントをAgent toolの `subagent_type` で起動すること。

**キーワード**: X、Twitter、SNS、投稿、広報、プレスリリース、LP、ランディングページ、コピー、バナー、広告、メルマガ、LINE、CRM、メール

## エージェント一覧

| エージェント名（subagent_type） | 専門 |
|-------------------------------|------|
| `SNSライター` | X運用・投稿文案 |
| `PRライター` | プレスリリース・広報 |
| `コピーライター` | LP・コピーライティング |
| `CRMマネージャー` | メルマガ・LINE・CRM |

## ルーティングロジック

```
「X・SNS・投稿」系 → Agent tool (subagent_type: "SNSライター")
「プレスリリース・広報」系 → Agent tool (subagent_type: "PRライター")
「LP・コピー・バナー・広告」系 → Agent tool (subagent_type: "コピーライター")
「メルマガ・LINE・CRM」系 → Agent tool (subagent_type: "CRMマネージャー")
「マーケ全体キャンペーン」系 → 複数を並列起動
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「X投稿を5案出して」 | Agent tool → SNSライター |
| 「プレスリリースを書いて」 | Agent tool → PRライター |
| 「LPのコピーを作って」 | Agent tool → コピーライター |
| 「メルマガのシナリオを設計して」 | Agent tool → CRMマネージャー |
