# /marketing — マーケティング部ルーター

## このコマンドの役割

マーケティング部への指示をルーティングする。

**キーワード**: X、Twitter、SNS、投稿、プレスリリース、広報、LP、コピー、広告、メルマガ、LINE、CRM、ブランド

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| Sho | `agents/04-マーケティング部/sho.md` | X運用・投稿文案 |
| Akari | `agents/04-マーケティング部/akari.md` | プレスリリース・広報 |
| Takumi | `agents/04-マーケティング部/takumi.md` | LP・コピーライティング |
| Hina | `agents/04-マーケティング部/hina.md` | 広告クリエイティブ |
| Yui | `agents/04-マーケティング部/yui.md` | メルマガ・LINE・CRM |

## ルーティングロジック

```
「X・SNS投稿」系 → Sho（レビューはTakumi）
「プレスリリース・広報」系 → Akari
「LP・コピー」系 → Takumi
「広告クリエイティブ」系 → Hina（+ Takumi でコピー連携）
「メルマガ・LINE・CRM」系 → Yui
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「X の投稿案を5つ作って」 | Sho |
| 「プレスリリースを作って」 | Akari |
| 「LPのコピーを改善して」 | Takumi |
| 「広告のクリエイティブ方針を決めて」 | Hina |
| 「今月のメルマガを書いて」 | Yui |
