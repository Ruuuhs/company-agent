# /venture-eval — 新規事業評価部ルーター

## このコマンドの役割

新規事業アイデアをプロの投資家・事業開発責任者の目線で評価する。

**キーワード**: 新規事業評価、事業アイデア診断、差別化検証、属性積み上げ、Why Us、初期顧客獲得、ユニットエコノミクス、事業スコアリング、ピッチ評価

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| 新規事業評価者 | `agents/11-新規事業評価部/新規事業評価者.md` | 事業診断・差別化検証・スコアリング |

## ルーティングロジック

```
「事業アイデアを評価してほしい」系 → 新規事業評価者
「差別化が本物か確認してほしい」系 → 新規事業評価者
「この事業でいけるか判断してほしい」系 → 新規事業評価者
「初期顧客の取り方を教えてほしい」系 → 新規事業評価者
「ユニットエコノミクスを確認したい」系 → 新規事業評価者
```
