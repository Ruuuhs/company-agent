# /content — コンテンツ制作部ルーター

## このコマンドの役割

コンテンツ制作部への指示をルーティングする。

**キーワード**: YouTube、動画、台本、コンテンツ、企画、サムネイル、教材、カリキュラム、編集、ネタ

## エージェント一覧

| エージェント | ファイル | 専門 |
|------------|--------|------|
| YouTube企画者 | `agents/03-コンテンツ制作部/YouTube企画者.md` | 企画・ネタ出し |
| 台本ライター | `agents/03-コンテンツ制作部/台本ライター.md` | 台本・スクリプト |
| ビジュアルデザイナー | `agents/03-コンテンツ制作部/ビジュアルデザイナー.md` | サムネイル・編集指示書 |
| 教材設計者 | `agents/03-コンテンツ制作部/教材設計者.md` | 教材・カリキュラム |

## ルーティングロジック

```
「YouTube企画・ネタ」系 → YouTube企画者
「台本・スクリプト」系 → 台本ライター（YouTube企画者の企画書を受け取り）
「サムネイル・編集指示」系 → ビジュアルデザイナー
「教材・カリキュラム」系 → 教材設計者
「動画を1本完成させたい」→ YouTube企画者 → 台本ライター → ビジュアルデザイナー（順次）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「YouTubeのネタを出して」 | YouTube企画者 |
| 「この企画の台本を作って」 | 台本ライター |
| 「サムネイルと編集指示書を作って」 | ビジュアルデザイナー |
| 「新しい教材のカリキュラムを設計して」 | 教材設計者 |
| 「来週のYouTube、全部準備して」 | YouTube企画者→台本ライター→ビジュアルデザイナー（順次） |
