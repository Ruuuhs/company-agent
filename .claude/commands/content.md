# /content — コンテンツ制作部ルーター

## このコマンドの役割

コンテンツ制作部への指示をルーティングする。
ユーザーの指示内容を判断し、適切なエージェントをAgent toolの `subagent_type` で起動すること。

**キーワード**: YouTube、動画、台本、スクリプト、企画、サムネイル、編集指示、教材、カリキュラム、コース設計

## エージェント一覧

| エージェント名（subagent_type） | 専門 |
|-------------------------------|------|
| `YouTube企画者` | YouTube企画・ネタ出し |
| `台本ライター` | 台本・スクリプト執筆 |
| `ビジュアルデザイナー` | サムネイル・編集指示書 |
| `教材設計者` | 教材・カリキュラム設計 |

## ルーティングロジック

```
「企画・ネタ」系 → Agent tool (subagent_type: "YouTube企画者")
「台本・スクリプト」系 → Agent tool (subagent_type: "台本ライター")
「サムネイル・編集」系 → Agent tool (subagent_type: "ビジュアルデザイナー")
「教材・カリキュラム」系 → Agent tool (subagent_type: "教材設計者")
「YouTube動画を一式作りたい」系 → YouTube企画者 + 台本ライター + ビジュアルデザイナー（順次）
```

## 典型的な指示例と対応

| 指示 | 起動エージェント |
|------|---------------|
| 「YouTubeのネタを出して」 | Agent tool → YouTube企画者 |
| 「この企画の台本を書いて」 | Agent tool → 台本ライター |
| 「サムネイルの方向性を決めて」 | Agent tool → ビジュアルデザイナー |
| 「新しい教材を設計して」 | Agent tool → 教材設計者 |
