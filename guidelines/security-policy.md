# セキュリティポリシー

## 基本方針

- 顧客情報・個人情報の保護を最優先とする
- 判断に迷う場合は「やらない」を選択する
- セキュリティインシデントが発生した場合は即座に代表に報告する

## 取り扱い禁止情報

以下の情報は、AIエージェントが処理・保存・送信してはならない：

- 個人の氏名・住所・電話番号・メールアドレス（マスクして扱う）
- クレジットカード情報・銀行口座情報
- パスワード・APIキー・秘密鍵
- 未公開の財務情報
- 契約交渉中の条件・金額

## データ保存ルール

| データ種別 | 保存場所 | 保存期間 |
|-----------|---------|---------|
| 議事録 | `outputs/meeting-logs/` | 3年 |
| 財務データ | `outputs/finance/reports/` または `outputs/finance/budgets/` | 7年 |
| 提案書 | `outputs/documents/proposals/` | 5年 |
| 契約書・NDA | `outputs/documents/contracts/` | 5年 |
| 戦略・競合レポート | `outputs/reports/strategy/` | 1年 |
| マーケティング成果物 | `outputs/reports/marketing/` | 1年 |
| リサーチレポート | `outputs/reports/research/` | 1年 |
| コンテンツ制作物 | `outputs/content/scripts/` または `outputs/content/visuals/` | 1年 |
| 一時作業ファイル | `outputs/tmp/` | 30日で自動削除 |

## 外部サービス利用ルール

- 新しい外部サービスの利用開始は代表承認が必要
- 無料プランのサービスにはビジネスデータを入力しない
- SaaSのデータ処理地域（リージョン）を必ず確認する

## インシデント報告フロー

```
問題発見
  ↓
作業を即時停止
  ↓
代表に報告（内容・影響範囲・発見日時）
  ↓
代表指示に従い対応
  ↓
再発防止策を guidelines に追記
```

## エージェントの自己点検チェックリスト

作業前に以下を確認：
- [ ] 個人情報を含むデータを扱っていないか
- [ ] 外部送信する情報に機密情報が含まれていないか
- [ ] 使用するツール・サービスは承認済みか
- [ ] アウトプットを保存するフォルダは適切か
