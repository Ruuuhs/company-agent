# リサーチプロトコル

## リサーチの基本フロー

```
1. リサーチ目的の明確化
2. 仮説の設定
3. 情報収集
4. 情報の整理・分類
5. 分析・考察
6. レポート作成
7. 代表へのブリーフィング
```

## 情報収集の優先順位

### 1次情報（最優先）
- 自社の顧客データ・アンケート結果
- 自社のKPIデータ
- 顧客インタビュー・VOCデータ

### 2次情報
- 政府・公的機関の統計データ
- 業界団体のレポート
- 上場企業の有価証券報告書・IR資料

### 3次情報（補完的に使用）
- ニュース・メディア記事
- 専門家のコラム・ブログ

## トレンド調査のチェックリスト

定期的に以下のトレンドを監視する：

- [ ] 業界全体のマーケット規模・成長率
- [ ] 技術トレンド（AI・DX関連）
- [ ] 競合の新サービス・機能追加
- [ ] 主要顧客層の行動変化
- [ ] 法改正・規制変更
- [ ] SNSでのバイラルコンテンツ傾向

## 情報の鮮度管理

| 情報種別 | 更新頻度 |
|---------|---------|
| 競合動向 | 月1回 |
| 市場データ | 四半期1回 |
| 法規制情報 | 随時 |
| VOCデータ | 月1回 |
| KPIデータ | 週次 |

## アウトプット形式

リサーチ結果は以下の構成でまとめる：

1. **エグゼクティブサマリー**（3〜5行で要点）
2. **背景・調査目的**
3. **調査方法・情報源**
4. **主要な発見事項**
5. **考察・示唆**
6. **推奨アクション**
7. **補足データ・出典リスト**
