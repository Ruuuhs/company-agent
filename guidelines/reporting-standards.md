# レポーティング基準

## レポートの種類と頻度

| レポート名 | 担当 | 頻度 | 提出先 |
|-----------|------|------|--------|
| 週次KPIレポート | データ分析部 | 毎週月曜 | 代表 |
| 月次事業振り返り | 経営企画部 | 月末 | 代表 |
| 競合動向レポート | リサーチ部 | 月1回 | 代表 |
| 経費レポート | 経営管理部 | 月末 | 代表 |
| 採用進捗レポート | 人事部 | 週次 | 代表 |

```markdown
## 良かったこと（Top3）
1.

3.

| 課題 | 原因（仮説） | 来週の対策 |
|------|------------|----------|
| | | |

## 来週の重点タスク
1. 
2. 
3. 
```

## 月次振り返りのフォーマット

```markdown
# 月次振り返り（YYYY年MM月）

## 今月の達成（Keep）
- 

## 課題・改善点（Problem）
- 

## 来月に試すこと（Try）
- 

## 数値サマリー
（主要KPIの月次推移）

## 来月の目標・重点施策
1. 
2. 
3. 
```

## 報告の鉄則

1. **結論を最初に書く** — 忙しい代表が最初の1段落で意思決定できるように
2. **数字を必ず入れる** — 「増えた」ではなく「前月比+15%」
3. **アクションを書く** — 問題提起だけでなく対策案を添える
4. **長さは適切に** — 週次は1ページ以内、月次は3ページ以内

## 緊急レポートのルール

予期せぬ問題が発生した場合は以下を即座に報告する：

```
【緊急報告】
発生日時:
内容:
現在の影響範囲:
暫定対応:
代表への確認事項:
```
