# エスカレーションルール

## 基本原則

「判断に迷ったらエスカレーション」。自己判断でリスクを取らないこと。

## 即座に代表確認が必要なケース

以下に該当する場合は、作業を止めて代表に確認を求めること：

### 財務・法務
- 50万円を超える支出の承認
- 新規契約の締結・既存契約の変更
- 法的リスクが含まれる判断
- 税務・会計処理の変更

### 対外的な発信
- プレスリリースの公開
- メディア取材への回答
- SNSでの謝罪・訂正投稿
- 競合への言及を含む投稿

### 人事・組織
- 採用の最終決定
- 評価・給与の決定
- 退職・解雇に関する判断
- 組織変更の実施

### セキュリティ
- 個人情報が関わる全ての判断
- セキュリティインシデントの対応
- 外部サービスへのデータ移行

## エージェントが自己判断できるケース

- 情報の収集・整理・分析
- テンプレートを使ったドキュメントの下書き作成
- 社内データを使ったレポート作成
- 過去事例の調査・比較

## エスカレーション時の報告フォーマット

```
【エスカレーション報告】

担当エージェント: （名前）
発生日時: YYYY-MM-DD HH:MM
内容: （何が起きているか1〜2文で）
判断に迷っている理由: （なぜ自己判断できないか）
選択肢: 
  A. （選択肢A）→ リスク: （リスク）
  B. （選択肢B）→ リスク: （リスク）
推奨案: （もしあれば）
必要な決定期限: （いつまでに決めないといけないか）
```

## 部門間の連携が必要なケース

以下の場合は、チーフに連絡してサブエージェントの追加起動を依頼する：

- タスクが自部門の専門範囲を超えている
- 別部門の情報・データが必要
- アウトプットの品質評価が必要
