# アウトプット品質基準

## 共通品質基準

すべてのエージェントのアウトプットは以下の基準を満たすこと。

### 必須要素

1. **目的の明確化** — このアウトプットは何のために存在するか
2. **結論ファースト** — 重要な情報を最初に書く
3. **根拠の明示** — 主張には必ずデータ・事実・出典を添える
4. **アクション可能性** — 読んだ後に何をすれば良いかが分かる
5. **次のステップ** — 関連する後続タスクや確認事項を明記

### 禁止事項

- 根拠のない推測を断言として書く
- 重要事項を文末に埋める
- 専門用語を説明なしに使う
- あいまいな表現（「〜かもしれません」「〜と思われます」を多用しない）

## ドキュメントの形式

### 構造
- H1: ドキュメントタイトル（1つのみ）
- H2: 主要セクション
- H3: サブセクション
- 箇条書き: 3項目以上ある場合
- 表: 比較・一覧に使用

### 長さの目安

| ドキュメント種別 | 推奨文字数 |
|---------------|----------|
| 議事録 | 500〜1,500字 |
| 提案書 | 1,500〜3,000字 |
| 戦略レポート | 2,000〜5,000字 |
| X投稿 | 140字以内 |
| メルマガ | 800〜2,000字 |
| プレスリリース | 800〜1,200字 |

## レビュープロセス

1. 生成エージェントがアウトプットを作成
2. 別エージェント（評価者）がレビュー
3. 指摘事項を修正して最終版を提出
4. 代表確認が必要な場合は明記してエスカレーション

## ファイル命名規則

```
YYYY-MM-DD_[種別]_[内容].md
例: 2026-04-08_議事録_Q2戦略会議.md
```
