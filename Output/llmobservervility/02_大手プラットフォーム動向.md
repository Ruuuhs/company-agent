# 競合分析レポート: 大手プラットフォームのLLM Observability参入動向

**作成日**: 2026-04-24
**作成者**: 競合アナリスト（経営企画部）
**分析対象**: Datadog / New Relic / Dynatrace / Splunk(Cisco) / Elastic / Grafana Labs / AWS CloudWatch / Azure Monitor / Google Cloud Vertex AI
**目的**: LLM Observability市場における大手プラットフォームの参入状況・機能・価格・戦略を明らかにし、自社が差別化できる領域を特定する

---

## エグゼクティブサマリー

データで見ると、2025〜2026年にかけてDatadog・New Relic・Dynatrace・Splunk・Elasticの大手Observabilityベンダー全社がLLM Observabilityを正式製品化しており、市場への参入は「これから起きること」ではなく「すでに完了した事実」である（公開情報）。クラウド3社（AWS・Azure・Google）も自社AI基盤との統合モニタリングを整備済みである（公開情報）。競合との差はどこにあるか？大手各社はいずれも「既存APM基盤へのLLM機能追加」という形態をとっており、LLMアプリケーション固有の評価（ハルシネーション・品質・セキュリティ）は後付け的な位置づけに留まる。OpenTelemetryによる標準化が進む一方、専門特化型ツール（LangSmith・Langfuse・Phoenix等）との機能差は依然として大きい。自社への含意は、既存APM顧客の「LLM監視を既存ツールに統合したい」という需要と、「LLM品質・ハルシネーション・コスト管理」に特化した深度の間に明確なギャップが存在することである。

---

## 1. 分析対象の選定理由

LLM Observability市場において、スタートアップ専門ツール（LangSmith・Langfuse・Helicone等）と並び、既存顧客基盤を持つ大手Observabilityプラットフォームが急速に参入している。大手は顧客の「ワンベンダー統合」需要を背景に強力な競合となりうる一方、LLM固有の深度では弱点を持つ。本分析では以下9社を対象に、機能・価格・ポジショニングを体系的に整理する。

## 3. 各社の詳細分析

### Datadog — LLM Observability

**事業概要** （公開情報）:
Datadogは2025年売上高33億ドルを記録した大手クラウドモニタリングプラットフォーム。2024年にLLM Observabilityを正式リリースし、同年EppoとMetaplaneを買収してフィーチャーフラグ・データObservabilityを統合。2026年5月1日から価格体系をスパン課金に移行する予定。

**価格・収益モデル** （公開情報）:
- 現行: $8 / 10,000 LLMリクエスト/月（約$0.0008/リクエスト）
- 2026年5月1日以降: LLMスパン数ベースの課金に移行
- AIワークロード追加後、既存Datadog利用者で40〜200%の請求増加が報告されている（推定・サードパーティ分析）

**強み**:
- 既存Datadogエコシステムとのシームレスな統合（APM・ログ・インフラを横断したend-to-endトレース）
- OpenAI・Anthropic・Bedrock・Azure OpenAI等への広範なプロバイダー対応
- OTel GenAI Semantic Conventions対応済み
- コスト自動算出機能（プロバイダー公開価格×トークン数で自動計算）
- Bedrock AgentCoreとの統合（NTT DATAが先行事例として発表）

**弱み**:
- スパン課金への移行でコスト予測が困難になる可能性
- LLM品質評価（ハルシネーション検出等）はスタートアップ専門ツールに比べ深度が浅い（考察）
- 既存Datadogユーザー以外への導入コストが高い

**最近の動向**:
- 2026年4月: Amazon Bedrock AgentCoreとの統合ガイドをNTT DATA事例とともに公開
- 2026年5月: 新価格体系（スパン課金）への移行予定

**自社への脅威度**: 高（圧倒的な既存顧客基盤とエコシステムが強み）

### New Relic — AI Monitoring / Agentic AI Monitoring

**事業概要** （公開情報）:
クラウドネイティブ向けObservabilityプラットフォーム。業界最大規模のフリーティア（月100GB）を武器に中小〜大企業に広く展開。2025年にAgentic AI Monitoringを発表し、自律型AIエージェントの可視化に注力。

**価格・収益モデル** （公開情報）:
- 無料枠: 100GB/月のデータインジェスト無料
- 有料: $0.40/GB（Original Data）または$0.60/GB（Data Plus）
- フルスタックフリーティアが競合優位の核

**強み**:
- 業界最大のフリーティアにより導入障壁が低い
- Agentic AI Monitoring: 複数エージェント間の相互依存関係を自動マッピング・可視化
- ハルシネーション特定に向けたエージェント推論トレーシング機能
- 780+インテグレーション対応
- MCP Server対応（AIエージェントとの連携）

**弱み**:
- データ量課金のため、LLMアプリは大量ログ生成によりコストが跳ね上がりやすい
- プロバイダー対応の広さではDatadog・Dynatraceに劣る（推定）
- エンタープライズ向けのセキュリティ統合はSplunkに比べて薄い（考察）

**最近の動向**:
- 2025年11月: New Relic NOW 2025でAgentic AI Monitoringを発表
- 2026年: Logs Intelligence（AI自動ログ解析）GA

**自社への脅威度**: 中〜高（フリーティアで開発者を取り込みやすい点が脅威）

### Dynatrace — AI Observability (Davis AI)

**事業概要** （公開情報）:
エンタープライズ向けフルスタックObservabilityの最大手の一つ。独自AI「Davis AI」を核に、自動因果分析・根本原因特定を提供。2025年5月にNVIDIA AI Factory統合を発表し、オンプレミスAIインフラの監視にも展開。

**価格・収益モデル** （推定）:
- Dynatrace Platform Subscription（DPS）ライセンス体系
- AI Observabilityの利用にはMetrics・Traces・Logs（いずれもGrailパワード）の契約が必要
- 具体的単価は非公開・要見積

**強み**:
- 対応テクノロジー20+（OpenAI・Bedrock・Gemini・Vertex・Anthropic・LangChain等）
- Davis AIによる自動異常検知・根本原因分析（LLM固有の問題にも適用）
- RAGパイプライン・エージェントフレームワークの依存関係を自動マッピング
- NVIDIA AI Factory検証済みデザインへの統合（2025年5月発表）
- コンプライアンス・プライバシー規制対応の観点でのガバナンス機能

**弱み**:
- 価格の透明性が低く、中小企業には参入障壁が高い（考察）
- 実装が複雑でオンボーディングコストが高い（考察）
- OSSエコシステムとの親和性ではGrafanaやNew Relicに劣る（推定）

**最近の動向**:
- 2025年5月: NVIDIA AI Factory統合発表
- 2026年3月: Intellyxによるフルスタック活用分析レポート公開

**自社への脅威度**: 中（大企業向けに特化しているため中小へのリーチは限定的）

### Splunk (Cisco) — AI Agent Monitoring

**事業概要** （公開情報）:
2024年にCiscoに買収されたSplunkは、Cisco統合セキュリティ・ネットワーク資産と掛け合わせた新しいObservabilityを展開中。2025年11月にAI Agent MonitoringをGA化し、セキュリティ統合（Cisco AI Defense）を最大の差別化軸に据える。

**価格・収益モデル** （公開情報）:
- Starter: $15/host/月、Growth: $60/host/月、Enterprise: $75/host/月（年間契約）
- 別資料では$95〜$200+/host/月との報告もあり（出典によって差異あり・推定含む）

**強み**:
- Cisco AI DefenseとのネイティブなPII漏洩・プロンプトインジェクション・ポリシー違反検出
- AI Agent MonitoringはOpenTelemetryとCisco AGNTCY標準準拠（ベンダーロックイン回避）
- NVIDIA NIM・Milvus・Pinecone・LiteLLM・GCP VertexAI等のAIインフラ幅広く対応
- Troubleshooting Agent（AIによるインシデント対応自動化）をGA
- MCP Server対応

**弱み**:
- Cisco買収後の統合過渡期による製品ロードマップの不透明さ（考察）
- 価格体系が複雑で中小企業向けの明確なエントリープランが見えにくい（考察）
- セキュリティ重点のポジショニングが、LLMパフォーマンス最適化ニーズとはずれる場合がある（考察）

**最近の動向**:
- 2025年9月: Cisco、Splunk Observabilityにアジェンティックアクを統合
- 2025年11月: AI Agent Monitoring GA（NVIDIA NIM等対応）
- 2026年Q1: AI Agent MonitoringのQ1アップデート発表

**自社への脅威度**: 中（セキュリティ統合が必要なエンタープライズ案件で競合になる）

### Elastic — LLM Observability

**事業概要** （公開情報）:
ElasticはSearch AI Platformを標榜し、OSSベース（Elasticsearch）の強みを背景にLLM Observabilityを展開。2025年にGartner Magic Quadrant for Observability Platforms（Leader）に選出。Azure AI Foundry・Google Vertex AI・Amazon Bedrockとの統合をGAとして提供。

**価格・収益モデル** （推定）:
- Elastic Cloud（SaaS）・セルフホスト・マーケットプレイス（AWS/Azure/GCP）経由で提供
- 具体的単価は非公開・プランにより異なる（要見積）

**強み**:
- Azure AI Foundry（2025年10月）・Google Vertex AI（GA）・Amazon Bedrockとの公式統合
- EDOT（Elastic Distribution of OpenTelemetry）による標準化された計装
- LangTrace・OpenLIT・OpenLLMetryなどサードパーティトレーシングライブラリとの互換性
- Bedrock Guardrails・Azure Content Filter等のセーフガード連携
- 2025年Gartner MQ Leader認定（公開情報）

**弱み**:
- Elasticの収益モデルはログ・検索基盤が中心のため、LLM Observabilityはあくまでアドオン（考察）
- Datadogのような一体型APMエコシステムには統合度で劣る（考察）

**最近の動向**:
- 2025年10月: Azure AI Foundry向けLLM Observability発表
- 2025年: Vertex AI向けLLM Observability GA

**自社への脅威度**: 中（マルチクラウド対応の幅広さが強みだが、専門特化ツールとの競合軸が異なる）

### Grafana Labs — AI Observability

**事業概要** （公開情報）:
OSSコミュニティに根ざした可視化・Observabilityプラットフォーム。2026年4月21日のGrafanaCON 2026（バルセロナ）でAI Observabilityを正式発表。Grafana 13とともにOpenTelemetry対応をさらに深化させた。

**価格・収益モデル** （推定）:
- Grafana Cloud既存プラン内でAI Observabilityを提供（追加課金体系は未公表）
- OSSのGrafana/Prometheusによるセルフホストも選択可能

**強み**:
- OpenTelemetry Technical Committee・Governance Committeeにメンバーを派遣するコアコントリビューター
- Grafana Alloy（OTel Collectorのディストリビューション）により計装が容易
- Grafana 13 + Loki新アーキテクチャによるスケール向上
- Grafana CLI（GCX）でCursor・Claude Code・GitHub Copilot等のAI開発環境と統合
- MS Teams統合・Python RuntimeによるAssistant拡張
- ベンダーニュートラルなポジショニングで開発者コミュニティへの訴求力が高い

**弱み**:
- AI Observability発表が2026年4月と各社に比べて遅い（事実）
- エンタープライズ向けのセキュリティ・ガバナンス機能は限定的（推定）
- ハルシネーション検出はregexベースに留まり、LLM品質評価の深度が低い（考察）

**最近の動向**:
- 2026年4月21日: GrafanaCON 2026でAI Observability正式発表（バルセロナ）
- 2026年4月21日: Grafana 13リリース

**自社への脅威度**: 中（OSS志向の開発者層への訴求力が高く、将来的に拡大する可能性あり）

AWSは自社AI基盤Amazon Bedrockと統合したCloudWatch Generative AI Observabilityをプレビューとして公開。AgentCore（AWSのマネージドエージェント基盤）との統合を中心に展開。

**価格・収益モデル** （公開情報）:

**強み**:

- 2026年: CloudWatch Generative AI Observabilityプレビュー開始
- AgentCore Quality Evaluations・Policy Controls追加

**自社への脅威度**: 中（AWSユーザーに対しては強力だが、マルチクラウド環境では限定的）

**強み**:

## 4. ポジショニングマップ

### マップ1: 価格帯 × 専門特化度

- **X軸**: 価格帯（左: 低コスト / 右: 高コスト・エンタープライズ向け）
- **Y軸**: LLM専門特化度（下: 汎用APMにLLM機能追加 / 上: LLM専門特化）

```
高専門特化
     ↑
     |  [LangSmith] [Langfuse] [Phoenix/Arize]   ← 専門特化型スタートアップ（参考）
     |
     |
     |     [Grafana Labs]    [New Relic]
     |  [Elastic]
     |                           [Datadog]
     |                                     [Dynatrace]
     |  [AWS CloudWatch]
     |  [Azure Monitor]
     |  [Google Cloud]
     ↓
低専門特化（汎用APMの拡張）
     ←低コスト────────────────────────────高コスト→
```

（考察）各社とも「汎用APMのLLM拡張」象限に集中しており、「高専門特化 × 低コスト」の領域に大手は未参入。

### マップ2: マルチクラウド対応 × セキュリティ統合度

- **X軸**: マルチクラウド対応（左: 単一クラウド特化 / 右: マルチクラウド対応）
