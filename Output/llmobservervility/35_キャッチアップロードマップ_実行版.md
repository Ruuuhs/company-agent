### 1-1. インフラ・ランタイム

| 項目 | 要件 | インストール方法 |
|------|------|---------------|

| Docker Compose | v2.x（Docker Desktopに同梱） | Docker Desktop付属 |
| Python | 3.11以上 | `pyenv install 3.11` または公式インストーラー |
| uv（Pythonパッケージマネージャー） | 最新版 | `curl -LsSf https://astral.sh/uv/install.sh | sh` |
| Git | 2.x以上 | 各OS標準の手順 |
| Node.js | 20 LTS以上（Promptfoo用） | https://nodejs.org/ |

### 1-2. APIキー

| サービス | 用途 | 取得先 |
|---------|------|-------|
| OpenAI API Key | LLM呼び出し・評価Judge用 | https://platform.openai.com/api-keys |
| Anthropic API Key | マルチプロバイダー比較用（任意） | https://console.anthropic.com/ |
| Langfuse Secret Key（クラウド版） | ローカル起動前の動作確認用（任意） | https://cloud.langfuse.com/ |

### 1-3. ローカルスタック（Week 1で構築）

```bash
# Langfuse v3 セルフホスト
git clone https://github.com/langfuse/langfuse.git
cd langfuse
docker compose up -d

# 確認: http://localhost:3000 にアクセスしてログイン画面が表示されること
```

| パッケージ | 使用開始週 | インストールコマンド |

### 1-5. サンプルデータ

- RAG評価用: Wikipedia APIから10〜20件の記事テキストをダウンロードして使う（特別なデータは不要）
- エージェント評価用: 「タスク管理Bot」シナリオ（例: Todoリストの追加・検索・削除）を自作する
- ゴールデンセット: 評価用の質問10件と期待回答を手動で用意（Week 6で作成）
