## 🎯 一言結論

**案C（PoC卒業支援＋内製化伴走）を起点に、12〜18ヶ月後に案A（業界特化）へ深化する二段階ロードマップが推奨**。収益立ち上げの速さ・LTVの高さ・垂直特化への移行パスを兼ね備えた最もバランスの取れた戦略。

---

## 🔑 調査から見えた3つの勝ち筋

### 1. 「作って終わり」から「運用して稼ぐ」への転換
市場は PoC 量産フェーズから **ROI検証・運用フェーズ** へ移行中。競合が PoC 受注を奪い合う中、「PoC卒業後の運用・改善」はホワイトスペースとして残存。月次保守 30〜500万 はストック収益として財務安定性を高める。

### 2. ドメインデータ蓄積こそ唯一の持続的参入障壁
AIコーディング価格破壊（Cursor / Claude Code / Devin）により「コードを書く力」は差別化にならない。差別化の源泉は **特定業界のドメイン知識・データ・ユースケースの蓄積**。Harvey（法務）/ Abridge（医療）/ Cresta（CS）が証明した勝ちパターン。

### 3. 受託をプロダクト化する「資産転換」設計
成功AIスタートアップ10社の共通パターンは **「受託案件から汎用化可能なコンポーネント・データセット・ノウハウを抽出してプロダクト化」**。受託単体はスケールしないが、最初から資産転換を意識した案件選別が3〜5年後の企業価値を決める。

## 🚀 推奨戦略と最初の3ヶ月アクション

### なぜ案Cを初手にするのか（3つの理由）

1. **創業初期の収益と信頼実績を最速で獲得** — 診断サービス（100〜300万）で入口ハードルが低く、3ヶ月で2〜3社との関係構築が現実的
2. **LTVが最大** — 診断 → 構築 → 伴走の三段階ファネルで1社あたりLTV 1500万以上を設計可能
3. **案Aへの自然な移行パスを含む** — 伴走顧客の業界を意図的に集積させることで、12〜18ヶ月後に「業界特化」へ無理なく転換できる

### 最初の3ヶ月 アクション5つ

1. AI導入診断サービスのパッケージ化（1ヶ月目）
2. パイロット顧客2社の低価格診断実施（2ヶ月目）
3. 診断サービスの提案テンプレート・成果物フォーマット標準化（2ヶ月目）
4. 深化対象業界（法務/医療/製造）の仮決定と業界有識者への接触開始（3ヶ月目）
5. 初期事例のコンテンツ化（ブログ・登壇資料）による認知形成（3ヶ月目）

## ❓ 代表に確認したい3つのこと

1. **業界絞り込みの意向** — 法務・医療・製造のどれに代表の経験・ネットワーク・関心が最も近いか？（案Aへの深化は代表の業界資産に依存）
2. **創業初期の収益目標と許容赤字期間** — 6ヶ月目の月次黒字化を目標とするか、12ヶ月間は投資フェーズと割り切るか
3. **創業時のエンジニアリソース** — 何名・どのスキルセットか（案Cはコンサル型人材が優先、案Aは業界特化人材が必須）
