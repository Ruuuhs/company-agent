# 仮想チーム for Claude Code

**やりたい仕事ごとに専門の AI が答えてくれる**、Claude Code 用のテンプレートです。
議事録づくり、採用計画、商談準備、SNS 投稿──話しかけるだけで、その分野に特化した AI が動き出します。

Claude Code とは、Anthropic 社が提供する、ターミナルやエディタ上で動く AI コーディング・業務アシスタントです。
**初めての人でも 10 分で動かせます。**

> **クローンした直後は汎用テンプレートです。使いながら育てることで、あなたの仕事にフィットしていきます。**

---

## こんなことで困っていませんか？

- Claude に毎回同じ会社情報を説明するのが面倒
- 1 人で全部やるには限界がある。戦略も採用も営業も、自分 1 人では回らない
- 専門ごとに相談できる相手が欲しい。でも、その都度プロンプトを書くのは手間

**このテンプレートはそれを解決します。**

---

## どんなことができるの？

**Claude Code に日本語で話しかけるだけで OK です。** 内容に応じて、その分野に特化した AI が自動で動き出します。

```
あなた: 明日の経営会議の議事録を、決定事項とアクション（誰が・いつまでに・何を）
       が1分で読める形でまとめて。

→ Claude が自動で議事録担当に振り分け、
  ・決定事項の一覧
  ・アクション項目（担当者・期限・内容）
  ・論点の要約
  を1分で読める議事録としてまとめてくれる
```

特定の分野に直接頼みたいときは、`/` から始まるコマンドで**明示指名**もできます。

```
あなた: /hr  エンジニアを3名採用したい。
            SES事業なので稼働率と収益への影響も踏まえた採用計画を立てたい。
            現在の稼働率は85%で、来期は案件が増える見込み。

→ 人事部の採用マネージャーが動き出し、
  ・稼働率・収益シミュレーション付きの採用計画
  ・市場需要に合わせた必要スキルセット定義
  ・求人票（SES特有の魅力訴求）
  ・面接評価シート（技術力 + 常駐適性）
  を作成してくれる
```

```
あなた: /sales  明日、株式会社○○との初回商談がある。
               相手は情報システム部の課長で、開発リソース不足が課題らしい。
               商談の進め方と事前準備を整理して。

→ 営業部の営業サポートが動き出し、
  ・想定される課題と切り口の仮説
  ・商談の進め方シナリオ
  ・事前に準備すべき資料リスト
  を出してくれる
```

> **普段は普通に話しかけるだけで OK。**「この部門に直接頼みたい」ときだけ `/` コマンドを使う、くらいの気持ちで十分です。

## はじめ方

### Step 0. Claude Code をインストールする

公式サイト（ https://claude.com/product/claude-code ）に従ってインストールしてください。
Mac / Windows / Linux で案内が異なるので、お使いの OS に合わせて公式の手順に従ってください。

### Step 1. Claude Code を起動して、作業したいフォルダで開く

Claude Code を起動し、作業したいフォルダ（例: `Documents` 配下など、好きな場所）を開きます。

### Step 2. このリポジトリを取り込む

以下のどちらかの方法で取り込みます。

**方法 A. Claude Code のチャット欄に頼む**

```
このリポジトリをクローンして: https://github.com/Ruuuhs/company-agent.git
```

**方法 B. ターミナルで直接実行する**

```bash
git clone https://github.com/Ruuuhs/company-agent.git
```

その後、クローンされたフォルダ `company-agent` を Claude Code で開き直してください。

> **「ターミナル」と「チャット欄」の違い**
> ターミナル = コマンドを実行する黒い入力欄。`git clone` のようなコマンドを打つ場所。
> チャット欄 = Claude に日本語で話しかける入力欄。お願いごとを書く場所。

### Step 3. `/setup` で自社情報を入力する

チャット欄に `/setup` と打つと、**インタビュー形式で自社情報を入力できます。**
会社名・事業内容・代表のスタイル・ブランドカラーなどを質問に答えていくだけで、
必要なファイルが自動で書き込まれます。

```
/setup
```

> **自分でファイルを直接編集したい場合** は `guidelines/` フォルダ内のファイルを開いてください。
> 各ファイルに「何を書くか」の説明とサンプルが記載されています。

### Step 4. 試しに使ってみる

セットアップが終わったら、普通に話しかけて動作確認してみましょう。

```
SES市場の直近トレンドと、採用に影響しそうな動向を調査して
```

部門を直接指名したいときは、先頭に `/` コマンドを付ければ OK です。

```
/research SES市場の直近トレンドと、採用に影響しそうな動向を調査して
```

## 使いながら、自分好みに育てる

このテンプレートは使い始めが完成形ではありません。
**使うたびに気になることが出てきたら、その場で育てていくのが正しい使い方です。**

### よくある「育て方」の例

```
担当者の口調が固すぎる
  → /edit-agent で「もっとフランクなトーンに変えて」と伝える

出力フォーマットが使いにくい
  → /edit-agent で「表ではなく箇条書きにして」と指示する

自社にない部門の担当者が邪魔
  → agents/ から不要なファイルを削除する

足りない役割がある
  → /add-agent で新しい担当者を追加する

会社の方針が変わった
  → /edit-agent または guidelines/ を直接編集して全員に反映
```

### カスタマイズ専用コマンド

| コマンド | 何をするか | いつ使うか |
|---------|----------|----------|
| `/setup` | 会社情報をインタビュー形式で入力。guidelines を自動書き込み | **最初に一回** |
| `/check` | 何が設定済みで未設定かを確認。次のアクションを提案 | 定期的に / 迷ったとき |
| `/add-agent` | 新しい担当者をウィザード形式で追加 | 足りない役割ができたとき |
| `/edit-agent` | 既存の担当者の動き方・出力・ルールを変更 | **動きが気になったらすぐ** |

> **コツ:** 「なんか違う」と感じたらすぐ `/edit-agent` を使うのが一番早いです。
> 試行錯誤しながら育てることで、自分の仕事にフィットしていきます。

### フォルダの説明

| フォルダ / ファイル | 何が入っているか | カスタマイズ方法 |
|------------------|--------------|--------------|
| `CLAUDE.md` | 司令塔の定義。Claude が誰に仕事を振るかを判断するルールが書いてある | 部門を追加・削除したら編集する |
| `agents/` | 担当者の指示書。仕事内容・ルール・出力テンプレートが書いてある | `/edit-agent` または直接編集 |
| `guidelines/` | 全員共通のマニュアル。会社の方針・ブランド・ルールをここに集約 | `/setup` または直接編集 |
| `templates/` | 書類のひな形。提案書・見積書など 13 種類 | 直接編集して自社フォーマットに |
| `.claude/commands/` | スラッシュコマンドの定義 | 部門を追加したときに編集する |
| `docs/` | このプロジェクトの背景と設計思想 | 参照用 |

## よくある質問

### 使う前の質問

**Q. Claude Code と Claude（claude.ai）の違いは？**
A. Claude（claude.ai）はブラウザで動くチャット型の AI アシスタントです。Claude Code はターミナルや IDE（エディタ）上で動く開発者向けツールで、ファイルの読み書き・コマンドの実行・プロジェクト全体の把握ができます。このテンプレートは、その Claude Code に「仕事用の専門チーム」をセットする仕組みです。

**Q. 料金はかかりますか？**
A. Claude の有料プラン（Pro / Max）または API 利用料が別途必要です。詳細は公式サイトを参照してください。

**Q. Windows でも使えますか？**
A. WSL（Windows Subsystem for Linux）または対応バージョンで動作します。詳細は Claude Code の公式サイトを参照してください。

**Q. プログラミングの知識がなくても使えますか？**
A. 使えます。ファイルはすべて日本語で書かれたテキストファイルです。Claude Code の使い方（チャットで話しかける）を知っていれば十分です。

### 使い始めた後の質問

**Q. 担当者の動き方が気に入らないときはどうすれば？**
A. `/edit-agent` を使ってください。「もっと短く」「表ではなく箇条書きで」「この表現は使わないで」など、気になったことを伝えるだけで担当者の設定を変更できます。使いながら少しずつ育てていくのが正しい使い方です。

**Q. 自社に合わない部門は削除できますか？**
A. できます。`agents/` フォルダから不要なファイルを削除し、`.claude/commands/` の該当コマンドファイルも削除してください。`CLAUDE.md` のルーティングテーブルからも該当行を消せば完了です。

**Q. 担当者が勝手に重要な決定をすることはありますか？**
A. ありません。各担当者には「自分で判断してよいこと」と「代表に確認が必要なこと」が明示されています。契約の締結・10%超の値引き・プレスリリースの公開などは必ず確認を求めます。

**Q. 担当者同士が勝手にやり取りしてループしませんか？**
A. しません。すべての指示は Claude（司令塔）を経由します。担当者同士が直接やり取りする設計にはなっていません。

## すでに Claude を使っている方へ

普通の Claude とこのテンプレートの違いを、使う前と後で比較するとこうなります。

| 普通の Claude | このテンプレートを入れた Claude Code |
|-------------|--------------------------|
| 何でも答えるが、毎回ゼロから説明が必要 | 会社のルール・ブランド・方針を覚えている |
| 汎用的な答えが返ってくる | 用途別に専門化された担当者として動く |
| 1つの会話で1つの仕事 | 1つの依頼から複数の担当者が並行して動く |
| 使い続けても変化しない | **育てるほど自分の仕事に馴染んでいく** |
