# 仮想チーム for Claude Code

**やりたい仕事ごとに専門の担当者が答えてくれる** Claude Code 用の設定ファイル一式です。
議事録づくり、採用計画、商談準備、SNS 投稿──話しかけるだけで、その分野に特化した担当者が動き出します。

Claude Code とは、Anthropic 社が提供する、パソコン上で動く AI アシスタントです。ファイルの読み書き、調べもの、複数の作業の同時進行などができます。
**Claude Code をインストール済みなら、セットアップから動作確認まで 10〜30 分ほどで動かせます。** 未インストールの場合はインストール時間が別途必要です。

> **クローンした直後は汎用の設定一式です。使いながら育てることで、あなたの仕事にフィットしていきます。**

---

## こんなことで困っていませんか？

- Claude に毎回同じ会社情報を説明するのが面倒
- 1 人で全部やるには限界がある。戦略も採用も営業も、自分 1 人では回らない
- 専門ごとに相談できる相手が欲しい。でも、その都度プロンプトを書くのは手間

**このテンプレートはそれを解決します。**

---

## 普通の Claude との違い

| 普通の Claude | このテンプレートを入れた Claude Code |
|-------------|--------------------------|
| 何でも答えるが、毎回ゼロから説明が必要 | 会社のルール・ブランド・方針を覚えている |
| 汎用的な答えが返ってくる | 用途別に専門化された担当者として動く |
| 1 つの会話で 1 つの仕事 | 1 つの依頼から**複数の担当者が同時に並列**で動く |
| 使い続けても変化しない | **育てるほど自分の仕事に馴染んでいく** |

### 仕組み（Agent tool で並列に動く）

Claude Code の **Agent tool（サブエージェント機能）** を活用し、各担当者が独立したコンテキストで動きます。

```
あなたの指示
  ↓
CLAUDE.md（司令塔）が指示を分類
  ↓
Agent tool で担当エージェントを起動（独立コンテキスト）
  ├── 戦略立案者     → 戦略立案
  ├── 競合アナリスト → 競合分析
  └── KPIアナリスト → 実績データ分析
  ↓
結果を司令塔が統合して報告
```

各担当者の定義は `.claude/agents/` に置かれており、Claude Code の Agent tool が自動で認識・起動します。

---

## どんなことができるの？

**使い方は基本 1 つだけ：Claude Code に日本語で話しかける。** 内容に応じて、その分野に特化した担当者に自動で振り分けられます。スラッシュコマンドは任意のオプションで、覚えなくても動かせます。

```
あなた: 明日の経営会議の議事録を、決定事項とアクション（誰が・いつまでに・何を）
       が1分で読める形でまとめて。

→ 議事録担当が自動で動き出し、
  ・決定事項の一覧
  ・アクション項目（担当者・期限・内容）
  ・論点の要約
  を1分で読める議事録としてまとめてくれる
```

```
あなた: 来月から新しい常駐案件に向けてエンジニア採用を強化したい。
       求人票・面接設計・SNS告知・採用ページのコピーを全部準備したい。

→ 採用マネージャー・SNSライター・コピーライターが並行で動き、
  ・求人票
  ・面接評価シート
  ・X投稿案
  ・採用LPのコピー
  を同時に揃えてくれる
```

### 部門を直接指名したいとき（任意）

短く特定の担当者を指名したい／出力の型を揃えたいときは、`/` から始まる**明示指名コマンド**を使えます。普段は使わなくても問題ありません。

```
あなた: /sales  明日、株式会社○○との初回商談がある。
               相手は情報システム部の課長で、開発リソース不足が課題らしい。
               商談の進め方と事前準備を整理して。

→ 営業部の営業サポートが動き出し、
  ・想定される課題と切り口の仮説
  ・商談の進め方シナリオ
  ・事前に準備すべき資料リスト
  を出してくれる
```

> **使い分けの目安**
> - 迷ったら／曖昧な依頼／複数の作業がつながるとき → **普通に話しかける**
> - 特定の部門を短く指定したい／いつも同じ担当者に頼みたい → `/` コマンド

## はじめ方

> **先に用語だけ押さえておきましょう**
> - **ターミナル** = コマンドを実行する黒い入力欄。`claude` や `git clone` のような命令を打つ場所。
> - **チャット欄** = Claude に日本語で話しかける入力欄。`claude` を起動したあとに出てくる、お願いごとを書く場所。
>
> ターミナルを使うのは **Step 0〜1（インストールと起動）だけ**。Step 2 以降はチャット欄に話しかけるだけで進みます。

### Step 0. Claude Code をインストールする

公式サイト（ https://claude.com/product/claude-code ）のインストール手順に従ってください。Mac / Windows / Linux で案内が異なります。

**完了の目印**: ターミナル（黒い入力欄）で `claude --version` と入力してバージョン番号が表示されれば成功です。次の Step 1 に進んでください。

> **Windows の方へ**: 公式手順に WSL（Windows Subsystem for Linux）のインストールも含まれており、**WSL から用意する場合はここで 30 分〜1 時間ほど余分にかかる可能性があります**。冒頭の「10〜30 分」は Claude Code がすでに使える状態の方向けの目安です。

### Step 1. 作業用フォルダで Claude Code を起動する

ターミナルを開き、作業したいフォルダへ移動して `claude` と入力するだけです。

```bash
# 例: Documents の下に新しいフォルダを作って、その中で起動する場合
cd ~/Documents
mkdir my-company-team
cd my-company-team
claude
```

`claude` を実行すると、その場でチャット欄が立ち上がります（Claude に日本語で話しかける入力欄）。
**最初にターミナルを使うのはここだけ**です。以降は基本的にチャット欄のやり取りだけで進められます。

### Step 2. このテンプレートを取り込む

Step 1 で開いたチャット欄に、下記をそのまま貼り付けて Enter を押してください。Claude が自動でクローンから後処理まで進めます。

```
このリポジトリをクローンしてください: https://github.com/Ruuuhs/company-agent.git
```

クローンが終わると、画面の指示に従って `company-agent` フォルダで Claude Code を開き直す流れになります。「一度 Claude Code を終了して、`cd company-agent && claude` で開き直してください」と案内されたら、ターミナルで同じコマンドを実行するだけで OK です。

<details><summary>ターミナル操作に慣れている方向け：手動でクローンする場合</summary>

Step 1 の代わりに、先にターミナルでクローンしてから Claude Code を起動することもできます。

```bash
cd ~/Documents
git clone https://github.com/Ruuuhs/company-agent.git
cd company-agent
claude
```

**どちらか一方の手順を行えば OK** です。両方やる必要はありません。

</details>

### Step 3. `/setup` で自社情報を入力する

チャット欄に `/setup` と打つと、**インタビュー形式で自社情報を入力できます。**
会社名・事業内容・代表のスタイル・ブランドカラーなどを質問に答えていくだけで、
必要なファイルが自動で書き込まれます。

```
/setup
```

> **「スラッシュコマンドは任意じゃなかった？」と思った方へ**
> 普段の業務は自然な日本語だけで動かせますが、**初期セットアップ（`/setup`）・設定変更（`/edit-agent`）・担当者追加（`/add-agent`）など"テンプレート自体をいじる操作"はスラッシュコマンドで行います**。日常業務では覚えなくて構いません。

> **自分でファイルを直接編集したい場合** は `guidelines/` フォルダ内のファイルを開いてください。
> 各ファイルに「何を書くか」の説明とサンプルが記載されています。

### Step 4. 試しに使ってみる

セットアップが終わったら、普通に話しかけて動作確認してみましょう。

```
自社の市場について、直近のトレンドと採用に影響しそうな動向を調査して
```

これで担当者（リサーチ部）が自動で動き出します。スラッシュコマンドは使わなくても構いません。

## 使いながら、自分好みに育てる

このテンプレートは使い始めが完成形ではありません。
**使うたびに気になることが出てきたら、その場で育てていくのが正しい使い方です。**

### まずは「1 人」から始める

24 人の担当者を一気に仕込もうとしないでください。**毎日やっている業務を 1 つ選んで、その担当者を自分専用に育てる**のがおすすめの始め方です。

1. **毎日やる業務を 1 つ選ぶ**
   - 議事録まとめ、SNS 投稿、メルマガ、商談メモ、求人票、経費チェック──「毎回同じことを説明しているな」と感じる作業が最適です。
2. **該当する担当者を見つける**
   - 下の「担当者の一覧」を見て、一番近い担当者を特定します（例：議事録なら経営企画部の議事録担当）。
3. **普通に話しかけて、1 回出力させてみる**
   - 例：「昨日の定例会議の議事録を、決定事項とアクションが一目で読める形でまとめて」
4. **違和感があれば `/edit-agent` で直す**
   - 「もっと短く」「表ではなく箇条書きで」「この表現は使わないで」──伝えるだけで担当者の設定が書き換わります。
   - **間違えても大丈夫**：書き換わるのは `.claude/agents/` 配下のテキストファイルだけです。気に入らなければ再度 `/edit-agent` で戻せますし、git で管理していれば `git diff` で変更内容を確認・巻き戻しできます。
5. **3〜5 回使ってフィットさせる**
   - 実際の業務で使い、違和感があればその場で微調整。数回で十分に「自分専用」になります。
6. **慣れたら 2 人目に広げる**
   - 1 人目が安定したら、次の業務の担当者を同じ手順で育てます。全員を同時に育てる必要はありません。

> **コツ:** 「なんか違う」と感じたらすぐ `/edit-agent`。**我慢して使うより、その場で直す方が 10 倍早く自分仕様になります。**

### よくある「育て方」の例

```
担当者の口調が固すぎる
  → /edit-agent で「もっとフランクなトーンに変えて」と伝える

出力フォーマットが使いにくい
  → /edit-agent で「表ではなく箇条書きにして」と指示する

自社にない部門の担当者が邪魔
  → .claude/agents/ から不要なファイルを削除する

足りない役割がある
  → /add-agent で新しい担当者を追加する

会社の方針が変わった
  → /edit-agent または guidelines/ を直接編集して全員に反映
```

### カスタマイズ専用コマンド

| コマンド | 何をするか | いつ使うか |
|---------|----------|----------|
| `/setup` | 会社情報をインタビュー形式で入力。guidelines を自動書き込み | **最初に一回** |
| `/check` | 何が設定済みで未設定かを確認。次のアクションを提案 | 定期的に / 迷ったとき |
| `/add-agent` | 新しい担当者をウィザード形式で追加 | 足りない役割ができたとき |
| `/edit-agent` | 既存の担当者の動き方・出力・ルールを変更 | **動きが気になったらすぐ** |

### フォルダの説明

| フォルダ / ファイル | 何が入っているか | カスタマイズ方法 |
|------------------|--------------|--------------|
| `CLAUDE.md` | 司令塔の定義。Claude が誰に仕事を振るかを判断するルールが書いてある | 部門を追加・削除したら編集する |
| `.claude/agents/` | 担当者の定義ファイル。Claude Code の Agent tool が自動認識する（frontmatter と指示書で構成） | `/edit-agent` または直接編集 |
| `guidelines/` | 全員共通のマニュアル。会社の方針・ブランド・ルールをここに集約 | `/setup` または直接編集 |
| `templates/` | 書類のひな形。提案書・見積書など 13 種類 | 直接編集して自社フォーマットに |
| `.claude/commands/` | スラッシュコマンドの定義 | 部門を追加したときに編集する |
| `docs/` | このプロジェクトの背景と設計思想 | 参照用 |

## 担当者の一覧（10 部門・24 人）

「部門」「担当者」と呼んでいますが、実体は**役割ごとに専門化された AI アシスタント**です。全員を使う必要はありません。自社の業務に近いところから触ってください。

- 01 経営企画部：3 人（戦略立案者・競合アナリスト・議事録担当）
- 02 事業開発部：2 人（事業企画者・収益設計者）
- 03 コンテンツ制作部：4 人（YouTube企画者・台本ライター・ビジュアルデザイナー・教材設計者）
- 04 マーケティング部：4 人（SNSライター・PRライター・コピーライター・CRMマネージャー）
- 05 人事部：2 人（採用マネージャー・組織デザイナー）
- 06 経営管理部：2 人（財務コントローラー・法務チェッカー）
- 07 リサーチ部：2 人（市場調査員・トレンドウォッチャー）
- 08 データ分析部：1 人（KPIアナリスト）
- 09 営業部：2 人（営業サポート・契約ライター）
- 10 M&A評価部：2 人（案件アナリスト・PMIプランナー）

> **読み方のコツ**: 下の一覧は**全部読む必要はありません**。ざっと眺めて「自分の業務に近いのは誰か」を 1〜2 人見つけられれば十分です。興味が湧いた担当者だけ展開してください。

## よくある質問

### 使う前の質問

**Q. Claude Code と Claude（claude.ai）の違いは？**
A. Claude（claude.ai）はブラウザで動くチャット型の AI アシスタントです。Claude Code はパソコン上で動き、ファイルの読み書き・複数の作業の同時進行・プロジェクト全体を踏まえた回答ができます。もともとは開発者向けのツールですが、ファイルを起点に何度も作業する用途に強いため、**業務ドキュメントの蓄積や会社運営の相棒としても使えます**。このテンプレートは、その Claude Code に「仕事用の専門チーム」をセットする仕組みです。

**Q. 料金はかかりますか？**
A. Claude の有料プラン（Pro / Max など）または API 利用料が別途必要です。プランごとの料金や含まれる機能は Anthropic 公式サイト（ https://claude.com/pricing ）をご確認ください。このテンプレート自体は無料で公開されています。

**Q. Windows でも使えますか？**
A. WSL（Windows Subsystem for Linux）または対応バージョンで動作します。WSL のインストールから案内する公式手順が Claude Code の公式サイトにあるので、そちらに沿って進めてください。

**Q. プログラミングの知識がなくても使えますか？**
A. 使えます。ファイルはすべて日本語で書かれたテキストファイルです。Claude Code の使い方（チャットで話しかける）を知っていれば十分です。

**Q. 入力した会社情報や会話内容はどこに保存されますか？**
A. `guidelines/` などの設定ファイルは**あなたのパソコン上のファイル**として保存されます（git で管理すれば履歴も残ります）。一方、Claude に話しかけた内容や回答は Anthropic のサービスを通じて処理されます。詳細は Anthropic の利用規約・プライバシーポリシーをご確認ください。機密性の高い情報を扱う場合は、自社のセキュリティポリシーに従って判断してください。

### 使い始めた後の質問

**Q. 担当者の動き方が気に入らないときはどうすれば？**
A. `/edit-agent` を使ってください。「もっと短く」「表ではなく箇条書きで」「この表現は使わないで」など、気になったことを伝えるだけで担当者の設定を変更できます。使いながら少しずつ育てていくのが正しい使い方です。

**Q. 自社に合わない部門は削除できますか？**
A. できます。`.claude/agents/` フォルダから不要なファイルを削除し、`.claude/commands/` の該当コマンドファイルも削除してください。`CLAUDE.md` のルーティングテーブルからも該当行を消せば完了です。

**Q. 担当者が勝手に重要な決定をすることはありますか？**
A. ありません。各担当者には「自分で判断してよいこと」と「代表に確認が必要なこと」が明示されています。契約の締結・10%超の値引き・プレスリリースの公開などは必ず確認を求めます。

**Q. 担当者同士が勝手にやり取りしてループしませんか？**
A. しません。すべての指示は Claude（司令塔）を経由します。担当者同士が直接やり取りする設計にはなっていません。

**Q. Agent tool とは何ですか？**
A. Claude Code に組み込まれたサブエージェント機能です。メインの会話から独立したコンテキストで別の Claude を起動し、専門的なタスクを実行させます。各担当者は独立して動くため、お互いの思考が干渉せず、並列に複数の仕事を進められます。

**Q. `/setup` の途中でやめてしまいました。やり直せますか？**
A. できます。もう一度 `/setup` と打てば、また最初から案内が始まります。分からなかった項目は「（未設定）」と記録されているので、**後から `guidelines/` フォルダ内のファイルを直接編集して埋める**こともできます。

**Q. うまく動かない・不具合に遭遇したら？**
A. このテンプレート自体に関する不具合・改善要望は、リポジトリの Issue（ https://github.com/Ruuuhs/company-agent/issues ）でお知らせください。Claude Code 自体の動作に関する問題は、Claude Code 公式のサポート・ドキュメントをご参照ください。
