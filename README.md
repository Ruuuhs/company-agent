# 仮想チーム for Claude Code

Claude Code 上で動く「AI 社員チーム」のテンプレートです。
**10 部門・24 人の AI 社員**があなたの会社の実務を担当します。

> **このリポジトリを自分の会社用にカスタマイズするだけで、すぐに使い始められます。**

---

## これは何？

一言で言うと、**Claude Code に「会社組織」を持たせる仕組み**です。

通常の Claude は何でも答えてくれる「万能アシスタント」ですが、このリポジトリを使うと Claude が **専門の担当者として動く** ようになります。

| 普通の Claude | このリポジトリを使った Claude |
|-------------|--------------------------|
| 何でも答えるが、深みが浅い | 担当者として深く・専門的に動く |
| 毎回ゼロから説明が必要 | 会社のルール・ブランド・方針を覚えている |
| 1人で全部やろうとする | 複数の担当者が同時に動いて効率化 |

---

## どんなことができるの？

Claude Code を開いて `/` からコマンドを打つだけで、専門の担当者が動き出します。

```
あなた: /content 今月のYouTube企画を3本考えて

→ YouTube企画者が動き出し、
  ・ターゲット設定
  ・タイトル候補（3パターン）
  ・競合分析
  ・サムネイルコンセプト
  ・動画構成
  をまとめた企画書を作成してくれる
```

```
あなた: /sales 昨日の商談をまとめて提案書を作りたい。内容はこれ→〔メモを貼り付け〕

→ 営業サポートが動き出し、
  ・商談議事録
  ・顧客の課題整理
  ・提案書（課題→解決策→費用対効果の順）
  ・見積書
  を作成してくれる
```

```
あなた: /marketing 新サービスのローンチ準備をまるごとやって

→ SNSライター・PRライター・コピーライターが同時に動き出し、
  ・X（Twitter）投稿文
  ・プレスリリース
  ・LP用キャッチコピー
  を並行して作成してくれる
```

## はじめ方

### Step 1. このリポジトリをクローンする

```bash
git clone https://github.com/Ruuuhs/company-agent.git
cd company-agent
```

> **クローンとは？** リポジトリ（ファイル一式）を自分のパソコンにコピーすることです。
> Claude Code のターミナル（画面下部の黒い入力欄）に上記を貼り付けて Enter を押してください。

### Step 2. 自社情報を入力する

以下の 2 ファイルを開いて、自社の情報を書き込んでください。
**ここが AI 社員全員の「会社の常識」になります。**

#### `guidelines/company-overview.md`
会社名・事業内容・ターゲット顧客・ミッションなどを記入します。

#### `guidelines/ceo-style-guide.md`
代表（あなた）の話し方・トーン・使ってほしい表現・使ってほしくない表現を記入します。
SNS 投稿や台本など、代表の言葉が必要な場面でこのファイルが参照されます。

### Step 3. Claude Code でこのフォルダを開く

Claude Code を起動し、クローンしたフォルダを開きます。
あとはチャット欄に話しかけるだけです。

## 使い方

### コマンド一覧

チャット欄で `/` を入力すると、以下のコマンドが使えます。

| コマンド | 担当部門 | こんなときに使う |
|---------|---------|--------------|
| `/strategy` | 経営企画部 | 事業戦略・競合分析・会議の議事録 |
| `/business-dev` | 事業開発部 | 新規事業・価格設計・収益モデル |
| `/content` | コンテンツ制作部 | YouTube企画・台本・サムネイル・教材 |
| `/marketing` | マーケティング部 | SNS投稿・プレスリリース・広告コピー・メルマガ |
| `/hr` | 人事部 | 採用・求人票・面接設計・オンボーディング |
| `/management` | 経営管理部 | 経費確認・予算管理・契約書チェック・法務リスク |
| `/research` | リサーチ部 | 市場調査・競合調査・AIトレンド・助成金情報 |
| `/data` | データ分析部 | KPI分析・ABテスト・数値レポート |
| `/sales` | 営業部 | 提案書・見積書・商談議事録・契約書 |
| `/ma` | M&A評価部 | 企業価値算定・デューデリジェンス・PMI計画 |

### コマンドの使い方

コマンドの後ろに、やってほしいことを自然な言葉で書くだけです。

```
/content  今月のYouTube企画を3本考えて。ターゲットは副業を始めたい会社員。

/marketing  新しいオンラインコースのX投稿文を5パターン作って。
            コース名は「AIで仕事を10倍速くする講座」。価格は49,800円。

/sales  明日、株式会社○○との初回商談がある。
        相手は中小企業の社長で、採用コストの削減が課題らしい。
        商談の進め方と、事前に準備すべきことを教えて。
```

### 複数部門にまたがる仕事は自動で振り分けられる

「新規事業のローンチ準備全部」のような大きなタスクは、Claude が自動で複数の担当者に振り分けます。
コマンドなしで普通に話しかけてもOKです。

```
新サービス「○○」を来月ローンチしたい。
LP・SNS・プレスリリース・見積書の準備を全部お願いしたい。

→ Claude が自動で
  コピーライター・SNSライター・PRライター・営業サポートを起動して並行作業
```

## AI 社員の一覧

### 01 経営企画部

| 担当者 | 仕事内容 |
|-------|---------|
| 戦略立案者 | 中長期の事業戦略を立案。「感情ではなくデータと構造で語る」がモットー。複数の選択肢と推奨案を必ず提示する |
| 競合アナリスト | 競合他社をデータで分析し「自社がどこで戦うべきか」を明確にする。事実・考察・示唆を分けて報告する |
| 議事録担当 | 会議の記録・アクション管理を担当。「誰が・何を・いつまでに」が1分で読める議事録を作る |

### 02 事業開発部

| 担当者 | 仕事内容 |
|-------|---------|
| 事業企画者 | 新規事業・新サービスの企画立案。「小さく始めてデータで育てる」思想で動く |
| 収益設計者 | 価格設定・収益モデル設計・外部パートナーとの連携スキームを構築する |

### 03 コンテンツ制作部

| 担当者 | 仕事内容 |
|-------|---------|
| YouTube企画者 | 「誰に・何を・なぜ今」の3軸で企画書を作成。競合分析・サムネイルコンセプトまで含む |
| 台本ライター | 代表の話し方を再現した台本を執筆。「最初の15秒で離脱を防げるか」を常に問いかける |
| ビジュアルデザイナー | サムネイル指示書・動画編集指示書を作成。「スマホの小さい画面で1秒で伝わるか」を基準にする |
| 教材設計者 | オンライン教材・カリキュラムを設計。「教えた」ではなく「使えるスキルになったか」を重視する |

### 04 マーケティング部

| 担当者 | 仕事内容 |
|-------|---------|
| SNSライター | X（旧Twitter）の投稿文案を作成。エンゲージメントの高い投稿パターンを熟知している |
| PRライター | プレスリリースを作成。「記者がこれを記事にしたいか？」の目線で書く |
| コピーライター | LP・広告・バナーのコピーを担当。必ず3案以上・訴求軸違いで提案する |
| CRMマネージャー | メルマガ・LINEのシナリオ設計。「受け取って嬉しい・読んで行動したくなる」を目指す |

### 05 人事部

| 担当者 | 仕事内容 |
|-------|---------|
| 採用マネージャー | 求人票・面接設計・採用戦略を担当。「条件で集める採用」より「理念で引き寄せる採用」を重視 |
| 組織デザイナー | 組織設計・オンボーディングプログラムを担当。新メンバーが早期に活躍できる環境を整える |

### 06 経営管理部

| 担当者 | 仕事内容 |
|-------|---------|
| 財務コントローラー | 経費チェック・予算管理・月次の予実対比を担当。「この支出、事業への貢献は？」を常に問う |
| 法務チェッカー | 契約書・利用規約の法的リスクをチェック。リスクを「高・中・低」で分類して対策をセットで提示する |

### 07 リサーチ部

| 担当者 | 仕事内容 |
|-------|---------|
| 市場調査員 | 市場規模・競合・顧客の声（VOC）を調査。「ソースはどこ？」「いつのデータ？」を常に確認する |
| トレンドウォッチャー | AIや技術の最新動向・助成金・政策変更を監視。自社事業への影響を早期に把握する |

### 08 データ分析部

| 担当者 | 仕事内容 |
|-------|---------|
| KPIアナリスト | 売上・登録者数などのKPIを分析。ABテストの設計・結果解釈も担当。「その数字、先月比でどう？」が口癖 |

### 09 営業部

| 担当者 | 仕事内容 |
|-------|---------|
| 営業サポート | 商談議事録・提案書・見積書を作成。「顧客の本当の懸念は何か？」を起点に提案を構成する |
| 契約ライター | 業務委託契約書・NDAなどを作成。取引を法的に適切な形で締結して会社を守る |

### 10 M&A評価部

| 担当者 | 仕事内容 |
|-------|---------|
| 案件アナリスト | M&A候補企業の調査・企業価値算定・デューデリジェンスを担当。感覚ではなく数字で評価する |
| PMIプランナー | 買収後の統合計画を立案。「Day1から1年後まで」のマイルストーンをシナジー定量化とともに設計する |

## フォルダの説明

各フォルダが何のためにあるか、一言で説明します。

| フォルダ / ファイル | 何が入っているか |
|------------------|--------------|
| `CLAUDE.md` | **司令塔の定義ファイル**。Claude がこのファイルを読んで「誰に仕事を振るか」を判断する |
| `agents/` | **AI社員の指示書**。各担当者の仕事内容・ルール・出力テンプレートが書いてある |
| `guidelines/` | **会社の共通マニュアル**。全員が守るべきルール・ブランドの方針・セキュリティポリシーなど |
| `templates/` | **書類のひな形**。提案書・企画書・見積書などの標準フォーマット（13種類） |
| `.claude/commands/` | **スラッシュコマンドの定義**。`/content` などのコマンドが何をするかを定義している |
| `docs/` | **このプロジェクトの背景解説**。なぜこの構成にしたかの思想が書いてある |

## よくある質問

**Q. プログラミングの知識がなくても使えますか？**
A. 使えます。ファイルはすべて日本語で書かれたテキストファイルです。Claude Code の使い方（チャットで話しかける）を知っていれば十分です。

**Q. 自社の情報を入力しないと動きませんか？**
A. 動きますが、「会社名」「代表の話し方」などが空欄のままだと、汎用的なアウトプットになります。`guidelines/company-overview.md` と `guidelines/ceo-style-guide.md` を埋めるほど、自社らしいアウトプットになります。

**Q. 担当者が勝手に重要な決定をすることはありますか？**
A. ありません。各担当者には「自分で判断してよいこと」と「代表に確認が必要なこと」が明示されています。契約の締結・10%超の値引き・プレスリリースの公開などは必ず確認を求めます。

**Q. 新しい担当者（エージェント）を追加できますか？**
A. できます。`agents/` フォルダに新しいファイルを作り、既存ファイルのフォーマットに倣って書くだけです。

**Q. 担当者同士が勝手にやり取りしてループしませんか？**
A. しません。すべての指示は Claude（司令塔）を経由します。担当者同士が直接やり取りする設計にはなっていません。
